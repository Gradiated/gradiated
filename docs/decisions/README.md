# Architecture and product decisions

Use this directory for durable decisions that affect multiple agents or workstreams: architecture boundaries, APIs, schemas, storage, provider choices, security posture, and operational contracts.

Create one dated record per decision using [`TEMPLATE.md`](TEMPLATE.md). Link the GitHub Issue, implementation paths, and evidence. Mark decisions `proposed`, `accepted`, `superseded`, or `rejected`; do not silently rewrite history.

Current records are numbered `0001` through `0009`. The newest decisions are [REST/OpenAPI/MCP and self-service deletion](0008-rest-openapi-mcp-and-self-service-deletion.md) and [multi-node owned inference](0009-multi-node-owned-inference.md).
