# Getting started with reinforcement learning

This directory holds reference material and working documentation for getting
started with reinforcement learning (RL).

## Reference material

- [Production traces to RL environments: reading list](PRODUCTION_TRACE_READING_LIST.md) — 18 papers covering failure diagnosis, executable environment generation, agent training, and cheaper adaptation baselines.
- [30_PRIME_RL_Async_Decentralize.pdf](30_PRIME_RL_Async_Decentralize.pdf) — useful systems paper for doing RL at scale.
