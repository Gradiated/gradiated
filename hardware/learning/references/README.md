# Learning references

ETH course-slide images are local study material and are not tracked in Git. On Aidan’s Mac, 32 images remain in `hardware/learning/references/slides/` and eight teaching extracts remain in `hardware/publishing/sand-to-thought/lectures/assets/`. Their bytes were verified against the preserved original consolidation before untracking. The narrowly scoped ignore rules prevent accidental addition. The original checkout and downloaded PDFs remain intact.

Repository notes link to the [official lecture decks](../../publishing/sand-to-thought/shared/sources.md#lecture-decks), retaining course editions and slide labels, so a fresh checkout does not need the local images. Do not assume printed slide numbers match PDF page numbers. These references support private study and teaching preparation, not permission to republish the images.
