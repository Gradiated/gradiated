## Format for future lectures

Start each new delivery script with **“What are we trying to get across?”**, immediately after the title. Use a few short bullets to state the main ideas the audience should retain, before the opening and detailed speaking notes. Keep this separate from the list of topics covered. Add the relevant scale, mechanism and trade-offs where they help; keep source qualifications in the references when possible.
