# Deep dives

Start with the [ideas backlog](ideas.md) and [existing research notebook](notes.md). These are open questions, not a fixed publication programme. Deep dives may cover any part of the computing stack and link to several overview chapters or subjects.

When an article starts, create a folder named for its question or subject. Add `notes.md`, `plan.md` and supporting material only as needed. Keep shared sources and conventions linked rather than duplicated. The current notebook remains intact so that early explanations and unresolved questions retain their context.

## First article in development

[How do we print a transistor onto silicon?](../articles/fabricating-a-transistor/plan.md) follows a simplified planar CMOS process through to a working NOT gate. The plan contains the agreed skeleton and scope, video references and proposed animations. The current work is planning only and remains local.
