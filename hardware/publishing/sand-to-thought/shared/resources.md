# Shared resources

Use `graphics/` for selected graphics genuinely reused across articles and `styles/` for shared website styles once they have been deliberately extracted. Both start empty. Post 001's active styling and diagrams remain together in its `web/` folder so the existing preview keeps working.

Do not copy files here merely to create a second working version. Record shared visual conventions in [STYLE_GUIDE.md](style-guide.md), and keep post-specific sources in the relevant post's `assets/` directory.
