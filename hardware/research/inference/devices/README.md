# Devices

Start with `kv260.json`. Before a physical run, record the actual board identity/revision, configuration, clocks, software/tool versions, cooling, supply and power measurement method. Unknown fields stay unknown, not inferred from a product name.

See [KV260 power telemetry](kv260-power-telemetry.md) for the sensor inventory, logger qualification and proposed energy measurement.

Device family specifications describe available resources, not achieved performance. Keep measured and vendor-reported values distinct. Additional CPU, GPU, FPGA or accelerator entries follow the same identity rules, with implementation-specific settings recorded in each run.
