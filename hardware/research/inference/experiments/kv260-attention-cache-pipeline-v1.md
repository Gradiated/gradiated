# Experiment 10 · Overlap cached reads and attention arithmetic

## Selection on 17 November 2026

The [attention profile](kv260-attention-profile-v1.md) is complete. All seven exact replays matched the adopted circuit. The cache had zero extra request or response stalls. The largest individual arithmetic opportunity was the three generic divisions inside a full softmax exponential. Applying the existing exact specialised division there predicts 11.5–16.1% fewer complete-request cycles across the three natural requests. We selected cache overlap for this experiment because it isolates a separate architectural question: can one memory port deliver the next word while the existing arithmetic uses the current word? It predicts 4.9–7.0% fewer cycles for the same requests. The exponential optimisation stays separate. The earlier profile and prediction retain their original bytes.

## One scheduling change

Use `attention-cache-pipeline-v1` against `ff-down-pipeline-v1`. Keep the model, clock, cache layout, one outstanding read, scalar work, arithmetic order, tags, saturation, numerical formats and host unchanged. Fetch the next key coordinate during the multiply-accumulate for the current coordinate within a score dot product. In the value pass, fetch the next cached position while accumulating the current position for one output coordinate. Let the first request of each sum occupy its own clock. Preserve the original order of MACs. If lookahead is refused, make the current MAC once and hold the same next request through the usual request state. A response still has to match the accepted address before it can supply operands. Reset cancels a pending response. A stalled final result holds its original value and tags.

At occupied length `L`, the original key and value pass together use `192L` clocks. The candidate hides `30L` key-request clocks and `32(L−1)` value-request clocks when each request and response is accepted at the first opportunity. The predicted saving is `62L−32` per position, with no change to cache transaction count or arithmetic work. The [preregistered per-case predictions](../implementations/kv260/variants/attention-cache-pipeline-v1/predictions.json) sum the same law over occupied positions for all original boundaries. Predicted complete-request counters are 6,128,767, 9,236,437 and 16,535,149.
