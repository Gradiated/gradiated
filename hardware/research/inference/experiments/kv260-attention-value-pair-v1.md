# Experiment 23 · Two lanes for attention value mixing

Start from the adopted [Experiment 22 circuit](../implementations/kv260/README.md#selected-circuit-comparison-baseline), `projections-read-ahead-v1`. Compare one and two value-mixing lanes within one head on the same 50 MHz KV260, using the frozen W16A16 model, weights, tokenizer, prompts, host, output caps and on-chip storage. Each lane calculates one output coordinate. Both use the same attention probability and take successive values from the same cached positions in their original order. The number of attention heads, the query–key scores, probability calculations, token selection and numerical rules stay fixed.

## Intervention and forecast

Pair adjacent value coordinates, split the existing 16 KiB V storage into even and odd banks, and supply two 16-bit values in one response during value mixing. Store each value once. Retain scalar reads for keys and the debug interface. An individual value write touches its own bank. Keep the single pending-response handshake, row commit and cache validity rules. Reuse the existing rounding unit and return the two results in coordinate order, including when the consumer stalls. Name this design `attention-value-pair-v1`. The board comparison measures the lanes and the cache changes together.

At occupied depth D, both designs use 32D weighted value terms for both heads together. The prediction for the value phase is 32 × (2D + 4) control clocks versus 16 × (2D + 7) candidate clocks with the consumer ready. This removes 16 request primes, 16D data clocks and 16D multiply-and-accumulate clocks per processed position. Predicted saving is 32D + 16, growing with the cache. This predicts 48, 528, 2,064, 4,112 and 8,208 clocks saved at occupied depths 1, 16, 64, 128 and 256. A natural reply ending after n processed positions would save 16n(n + 2) clocks, including stopping. Predicted completion savings for Hello, six bytes and 48 bytes are 166,448, 295,920 and 652,848 clocks. Hypothesise one additional multiplier and the same logical cache capacity. Inspect actual mapped memory blocks, arithmetic resources, port organisation, clock coverage and timing.

## Qualification and measurement

Check directed stalls, reset, full and partly committed rows, both heads, odd and even occupied lengths, read tag and responses, signed extremes, probability 32768, ties, clipping and stable ordered outputs. Check logical keys and values independently of physical cache transactions. Compare each head, position and coordinate's probability, cached value, product, running sum, rounded result, and numeric scores and termination, including capped/empty output. Replay all seven frozen cases on both arms. Record value-phase clocks, read requests and responses, stalls, useful work and whole-prediction cost at matched cache depths on the same sequence. Mark any derived full-step counts explicitly. Reconcile cumulative savings and actual first/last/done boundaries. Keep unrelated stage timings and output work comparable. Bound each full replay to 30 minutes.

Route one qualified design at 50 MHz and record the shell/interface pins, utilisation and timing, including mapped resources in cache and attention. Bound route to 42 minutes, programming-image packaging to three minutes and resumable archive recovery to 20 minutes. Allow a bounded corrective attempt for a diagnosed failure. Qualify the exact standard board packet against the RTL and implemented design.

Use [measurement standard v2](measurement-standard-v2.md) and the [Experiment 22 schedule](kv260-projections-read-ahead-v1.md). Run A1/B1/B2/A2, nine smoke checks, 36 warm-ups and 200 timed requests in 20 powered blocks. Report exact work and FPGA clocks, per-prompt board-side TTFT, decode TPS and completion, active/idle watts, VCC_SOM gross J/answer, J/useful token and tokens/J, mixed and homogeneous blocks, paired variation, temperatures, failures and sample/peripheral checks. Preserve raw data on the Mac. Allow 30 minutes for board measurement plus three minutes to restore the original research circuit and weights. Verify all 320 original BOS scores, stock clocks, firmware, permissions and cleanup. Scope ends with Experiment 23.
