# Exact fixed-denominator division in the feed-forward exponential

Test whether skipping unnecessary leading quotient digits in the three feed-forward exponential divisions speeds up the adopted eight-lane circuit. The frozen W16A16 model, cache, generic sigmoid division, other scalar instances, scoring circuit, 50 MHz target, request schedule and host observer stay fixed. The [cycle profile](../results/ff-profile-rtl-20261116T211748Z/findings.md) measured 12,672 clocks per processed position in the three fixed-denominator divisions.

## Exact arithmetic

Let D be 45,426 and N be the magnitude of the original signed numerator. Split N into a high prefix P and k low bits. When P < D, the quotient of P by D is zero and its remainder is P. Starting the original restoring divider with quotient zero and remainder P is therefore equivalent to processing that prefix normally. At each subsequent step the divider computes a trial from four times the current remainder and two new numerator bits. It subtracts the largest fitting multiple of D and appends the quotient digit. This maintains the same quotient and remainder invariant through the final bit pair. The existing finish state handles ties to even, restores the sign and applies the original overflow check.

| Caller | Bound on N for every supported exponential input | Low bits retained | Prefix upper bound |
| --- | ---: | ---: | ---: |
| Range reduction | 2^20, after the original argument rejection and shortcut | 6 | 16,384 |
| Table address | 45,425 × 256, from the first exact remainder | 8 | 45,425 |
| Interpolation | 2^31 × 45,425, with any loaded legal table values | 32 | 22,712 |

The third bound holds for any legal table because a pair of table values is in the inclusive interval from zero to 2^31. Their signed difference has magnitude at most 2^31. The multiplier's signed result fits in 64 bits. A full-width magnitude retains the representation of INT64_MIN. The guard takes the original 32-step divider if the prefix is too large or the caller is unrecognised, preserving the exact result over the remaining signed 64-bit domain.

Only the three exponential callsites in a clone of the feed-forward scalar use this start. The generic variable denominator division and the shared scalar source retain their original logic. The clone is included in generated feedforward.sv so the other ten generated RTL files remain byte-identical.
