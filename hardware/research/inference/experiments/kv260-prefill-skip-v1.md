# KV260 intermediate prompt score skipping

## Question and prediction

Does skipping the unused vocabulary projections reduce time to first token on the KV260? The comparison uses the adopted autonomous-v1 image and a separately named prefill-skip-v1 image. Both run the frozen W16A16 model at the same reported 50 MHz. Both process every input position and retain final normalisation, the KV cache contents, the final prompt projection and every decode projection.

Each omitted 320-score projection schedules 32 read/multiply-accumulate pairs, one rounding state and one output state per score. That is about 21,120 active cycles or 0.4224 ms per omitted position at 50 MHz. The three frozen prompts have 11, 13 and 97 input IDs including BOS, so the analytical projection savings are about 4.22, 5.07 and 40.55 ms before controller and observation boundaries. Transformer computation and the final projection remain. Steady decode should show little change. Confirm both expectations against matched simulation and measure the board separately.

A skipped projection cannot report saturation that would have arisen inside that projection. Preserve the upstream saturation checks and all full-score fault checks. Exact equivalence is tested on frozen admitted inputs and states.
