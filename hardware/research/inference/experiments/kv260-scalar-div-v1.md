# KV260 exact scalar division

Compare scalar-mul-v1 (adopted control) with scalar-div-v1. Both run the frozen chip-joke-text-20261109 W16A16 model with the same multiplication, tables, number formats, native reader, AU02 interface, KV layout, requests and 50 MHz clock. Replace only the generic bit-serial divider with a restoring divider that consumes two bits per step. Thirty-two two-bit steps and a separate finish clock replace 64 bit-serial steps. The hypothesis is that the measured division waits will fall by up to 31 cycles per call with no accuracy loss.
