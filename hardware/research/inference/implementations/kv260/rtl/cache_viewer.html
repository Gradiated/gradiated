KV cache: remember a token’s numbers

Each token contributes 32 rotated K values and 32 unchanged V values. Two memories store them. A token becomes readable only after all 32 K/V pairs arrive. This is observed circuit simulation on a Mac.

The table reconstructs stored bits from observed writes or the verified full-cache readback. Partial and reset-invalid bits are shown for teaching; the controller refuses reads of those tokens. Selecting a cell replays recorded data, not a new hardware operation.

What was tested?

One fixture contains the full integer model's K-after-RoPE and V cache for a synthetic repeated 256-token sequence. Two additional fixtures use distinct address patterns and seeded random signed16 values. Every address is read back, with stalls, invalid requests, full-cache overflow, partial writes and resets checked independently in Python.

This is a separate cache controller simulated in Verilator on the Mac. Python supplies K/V. It is not yet connected to the projection/RoPE blocks or attention. The 32 KiB capacity is logical storage, not measured BRAM mapping. Synthesis, physical FPGA execution, timing and energy are later work.
