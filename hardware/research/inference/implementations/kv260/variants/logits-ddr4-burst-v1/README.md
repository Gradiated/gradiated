# Feed the eight final-score lanes from DDR4

The [Experiment 13](../../../../experiments/kv260-attention-exp-pair-v2.md) circuit is the exact control. The candidate keeps the on-chip tied input embedding and removes the eight full logits coefficient banks. A separate private 20,480-byte DDR window contains the same frozen bank-0 weights, packed by group, coordinate and lane. Within an eight-token group, the two consecutive 64-bit response beats for a coordinate contain lanes 0–3 and lanes 4–7.

The candidate requests eight aligned, eight-beat AXI INCR bursts for each 512-byte group. Two local 32-word, 64-bit banks stage the complete group before the existing eight-lane dot products begin. The next group does not request weights before the current group has streamed all eight scores. MAC sequencing, signed arithmetic, rounding and stream order are unchanged. For a scored position, the DDR reader accepts 320 addresses and 2,560 beats. It transfers and consumes 20,480 bytes. Prompt-only positions keep the adopted skip behaviour.

Register `0x60` sets a 64-byte aligned, nonzero device-visible base of at most `0x7fffb000`. Write it while the DDR path is disabled and the reader and model are idle. Register `0x64` enables or disables the required DDR path while idle. Its readback bits 0–4 report enable, transport busy, sticky fault, safe release and counter saturation. Fixture ID `0x8c` reads `0x44445233` (`DDR3`). The candidate accepts the original bank-0 loader traffic for local embedding only. It refuses inference starts while the DDR path is disabled.

The counter offsets match Experiment 14. Useful bytes at `0x68` count 16 per MAC clock. `0x6c` counts accepted addresses, `0x70` accepted beats, `0x74` faults, `0x78` extra clocks, `0x7c` address stalls, `0x80` response waits, `0x84` scored invocations and `0x88` score projection busy clocks. Per successful invocation the busy total equals 1,680 original projection clocks, 2,880 fixed staging clocks, and observed address and response waits. The fixed component is 40 groups × (one launch edge + eight address acceptance edges + 63 response edges before group capture). The final response edge doubles as the original PRIME capture edge.

On cancel or fault, the reader preserves a stalled address and drains the issued burst before buffer release. It stops issuing later bursts in the abandoned group. A wrong ID or premature RLAST cannot prove completion. A broken slave can withhold release after inference terminates. Full software reset disables DDR and drops the unfinished group, while the AXI reader still drains the original burst. The host releases memory only after verified idle and disabled readback.
