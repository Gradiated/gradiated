# Prefetch the next DDR4 score group

[Experiment 17](../../../../experiments/kv260-logits-ddr4-prefetch-v1.md) compares two circuits that score the same 320 tokens in groups of eight. The control fills one 512-byte buffer before every group. The candidate adds a second slot and can fill group N+1 while consuming group N. Address order, eight-beat bursts, the 20,480-byte packed table, the on-chip input embedding and the score arithmetic all use the [Experiment 16 interface](../logits-ddr4-burst-v1/README.md).

The two 64-bit storage halves have 64 addresses each. The high address bit selects the slot and the other five select a coordinate. A group becomes available only after its final valid response. On the first operand read, a group can complete and provide coordinate zero on the same edge because the final beat writes coordinate 31. The next group uses the opposite slot and can launch once the current group is complete. The group pointer caps prefetch at one group ahead and never advances into a new invocation. A bad or cancelled next-group read invalidates staged data. An asserted address or issued burst drains under the same rules as the control before DMA memory can be released.

The adapter and temporary-driver ABI are byte-identical, including the DDR3 fixture ID. Register `0x78` counts score clocks exposed to unavailable operands. For a successful invocation, accepted reads plus accepted beats plus address stalls plus response waits give the interface service clocks. The reader also spends one launch clock per group. Add the 40 launch clocks to interface service, then subtract exposed waits and the 40 original coordinate-zero capture clocks to infer the clocks recovered from overlap. Equivalently, the inferred value is the interface service count minus the exposed-wait count. The model replay measures overlap directly by scoring phase and keeps accepted AXI handshake overlap separate from reader work clocks. With the autonomous result sink ready, projection-busy clocks equal `1680 × scored invocations + exposed clocks`.
