# Experiment 17 board comparison

The board packet contains the two routed DDR4 images, identical shared DMA and interface overlays, the byte-pinned Experiment 16 Linux driver and packed logits matrix, and the scripts run on the board. One detached board supervisor owns the KV260 lifecycle and restores original state even if the Mac serial connection pauses. A single supervisor launches only after the independently checked packet and its same-boot restoration anchor have passed. Each change of image follows checked DMA release, module unload and verified HP0 restoration.

The Mac tools prepare a packet from the completed offline acceptance receipt with `prepare_packet.py`, then create the resumable UART transfer with `transport.py prepare`. Run `verify_packet.py` against the recovered Experiment 16 invocation and the current boot's reused-file checksum receipt before staging it. `stage_parts.py` sends independent bounded slices and checks each reconstructed digest. `transport.py run` dispatches the sealed task, `status` retrieves wall-clock-stamped outcome receipts, and `collect` recovers the immutable board payload in independently hashed slices. See the executed [protocol](../../../../../experiments/kv260-logits-ddr4-prefetch-v1.md) for the admitted sequence and limits.

`score_fixture.py` audits request identity, traffic, FPGA clocks, energy integration and continuous arm boundaries from raw board captures. It distinguishes accepted bus work, exposed score-stage wait and inferred overlap. `write_record.py` checks the exact routed image pins, the raw archive and live restoration before emitting the immutable physical record.
