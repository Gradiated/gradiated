# Shorter exact attention probability division

[Experiment 18](../../../../experiments/kv260-probability-div-v1.md) starts from the selected 50 MHz `attention-exp-pair-v2` circuit. The generator verifies the adopted source manifest and every RTL member. The candidate changes only `attention.sv`. The primary attention scalar opts in to a short division schedule for its probability command. The second scalar uses its existing exponential schedule.

## Integer proof

Attention loads a context of 1–256 positions per head. It admits and commits only unsigned exponential values in [0, 2³¹]. The 64-bit accumulator starts at zero on each head. It adds every committed exponential once, in order, before the first probability command. Consequently the complete sum S is at most 256 × 2³¹ = 2³⁹, and each stored E satisfies 0 ≤ E ≤ S. The controller rejects S = 0 and still checks its original upper limit. The largest dividend E × 2¹⁵ is 2⁴⁶. Both operands therefore fit as nonnegative signed 64-bit values, including the exponential word `0x80000000` which the controller zero-extends.

Write N = E × 2¹⁵ = 2¹⁶P + L, with 0 ≤ L < 2¹⁶ and P = floor(E/2). If E = 0 then P = 0 < S. If E > 0 then P < E ≤ S. In the baseline, 24 radix-four steps consume N[63:16]. Every consumed prefix is at most P, so it is smaller than S. All 24 quotient digits are zero and the remainder after those steps is P. The candidate seeds this remainder, shifts L into the high 16 bits of the input register and sets its counter to eight. Those fields are exactly the baseline register state after step 24. The denominator, its triple, the sign, the rounding flag and the return state are identical.

The common recurrence appends the next base-four digit to the current remainder and selects the largest of 0, S, 2S and 3S that fits. With a current remainder below S its trial is below 4S, so subtraction yields the same next digit and remainder with both schedules. At completion both registers hold the exact floor quotient q and remainder r. The unchanged rounding compares 2r to S and increments for a strict majority or for an exact tie with odd q. For E = 0 the output is 0. For E = S > 0, q = 32,768 and r = 0. All supported rounded results fit the original unsigned 16-bit probability.

The fast path checks the sufficient condition directly with a zero-extended unsigned prefix and the unsigned view of the already validated positive denominator. Negative inputs and prefixes at or above the divisor follow the full signed divider schedule. The denominator checks execute before either path. The generic scalar module used elsewhere has the original source. Other commands in the attention scalar use their original dispatch and subroutines. Only probability issues an external divide command to the enabled instance in this design. A future caller that sends another nonnegative dividend with an eligible prefix to that same instance will get the same exact result in eight steps. The default scalar parameter preserves the original schedule.

## Reproduction

Use Python 3.10 or later and the pinned Verilator 5.052 installation. Run `materialise_probability_div.py --arm control` and `--arm candidate` with separate `--output` paths. Use `replay_probability.py` with the exact Experiment 13 simulation archive identified by its SHA-256. It compiles both arms and compares the replay with the adopted traces, audits every architectural probability with Python integer division and verifies the saved clocks at each context depth and request boundary. Use `test_directed.py` with the frozen model hex file extracted by the replay. It checks raw signed and unsigned division, the scalar interface, and the paired attention controller against the independent integer references.
