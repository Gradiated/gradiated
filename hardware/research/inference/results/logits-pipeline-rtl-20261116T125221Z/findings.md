# Final token-score pipeline matched RTL simulation

`logits-pipeline-v1` and the selected `scalar-div-v1` control passed all seven frozen cases on the pinned Verilator 5.052 toolchain. Each arm matched 103,360 retained signed scores, valid key/value cache snapshots, generated byte IDs and stop reasons. Intermediate prompt-score skipping, zero- and one-byte caps, context limit, AXI handshakes, clear and both legacy BOS requests in every case passed.

The standalone component test matched all 10,240 ordered products and running sums per arm at both result widths. Synthetic data covered positive and negative ties, signed product extremes and clipping with a narrower output. It also covered cancellation at every active first-row offset, a stalled result and the next-row boundary.

| Prompt | Prefix cycles in both arms | First-byte cycles, control → candidate | Complete-request cycles, control → candidate | Complete-request reduction |
| --- | ---: | ---: | ---: | ---: |
| Hello | 578,313 | 599,435 → 589,515 | 9,568,145 → 8,665,425 | 9.43% |
| Encoded six-byte prompt | 690,195 | 711,317 → 701,397 | 14,002,477 → 12,782,317 | 8.71% |
| 48-byte prompt | 7,257,835 | 7,278,957 → 7,269,037 | 22,523,587 → 21,481,987 | 4.62% |

The prefix boundary is entry into the final prompt's score projection. It moved by zero cycles in all seven cases. Each retained projection saved exactly 9,920 clocks in `LOGIT_WAIT`. First byte saved 9,920 clocks when present, and no other phase changed. At an assumed 50 MHz, that is 0.1984 ms per projection. The rate and timing conversion are analytical. The board, routed resource counts and power were outside this run.

The candidate changes only the generated `transformer.sv` file. It uses the same read ports and arithmetic lane to overlap reads with arithmetic within each row.
