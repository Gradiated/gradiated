## Capacity and cost conclusion

For the shorter workload, concurrency 12 is the latency-oriented operating
point and 16 is the throughput ceiling. Requests above 16 should spill to
another node or be rejected; concurrency 24 reduced throughput and sharply
increased tail TTFT.

The Nebius account calculator returned $4.50/hour and $3,285 per 730-hour month
for the VM preset, excluding storage and AWS/VPN costs. At the sustained
short-workload peak this is $2.052 per million output tokens or $0.476 per
million total processed tokens. At production prices of $0.12/M input and
$0.35/M output, fully utilized revenue is $1.639/hour versus $4.50/hour compute,
a $2.861/hour or $2,089/month compute loss. Break-even requires approximately
2.75 times the current input and output prices before ancillary costs.

## Multi-turn coding-agent replay

The production-shaped workload is a deterministic 64-session sample from
`thoughtworks/agentic-coding-trajectories`. It replays multiple conversations
in parallel and sends each original conversation prefix immediately before an
assistant turn. The sample is constrained to 4,500–6,200 source tokens because
the corpus uses `cl100k_base`, while this runtime currently has an 8,192-token
Gemma context limit.

The runtime for this experiment allowed up to 48 running requests. These are
scheduler operating points, not a recommendation to admit 48 requests.

### Cheapest-price economics

OpenRouter's cheapest listed Gemma 4 provider price at measurement time was
$0.08/M uncached input, $0.01/M cache read, and $0.35/M output. The sustained
c10 run processed 1,112,702 cached input tokens, 156,257 computed input tokens,
and 38,400 output tokens in 121.541 seconds.

| Component | Gross revenue/hour |
|---|---:|
| Cache-read input | $0.330 |
| Uncached input | $0.370 |
| Output | $0.398 |
| **Total** | **$1.098** |

This covers **24.4%** of the $4.50/hour H200. The gross compute loss is
$3.402/hour, or approximately $2,484 per 730-hour month. This excludes storage,
AWS, VPN, control-plane cost, and any commercial deductions. Proportional
break-even pricing would be 4.10 times the cheapest prices.

Concurrency 10 is the current balanced operating point. Its 0.797-second p50
TTFT and 42.45 tok/s p50 decode are competitive with standard GPU providers,
while its 3.874-second p50 request time for 128 generated tokens remains close
to the fastest low-price providers. Concurrency 12 and above recover more cost
in saturation tests, but per-request throughput and tail TTFT degrade enough to
risk worse routing rank.
