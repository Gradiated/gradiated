# Website instructions

Read and follow the parent `product/AGENTS.md` first.

## Visual restraint

- Default to typography and whitespace. Do not add horizontal rules, bordered cards, section dividers, or decorative boxes unless they communicate a necessary grouping that spacing cannot.
- Do not add eyebrow or kicker text above a heading when it merely repeats the page or section name.
- Shared components may add visual chrome by default. Opt out when that chrome does not serve the page rather than accepting it automatically.
- Preserve existing visual elements when editing an established page unless the task calls for a redesign.
