## Messages

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from anthropic import Anthropic
import os

client = Anthropic(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
)

message = client.messages.create(
    model="YOUR_MODEL",
    max_tokens=256,
    messages=[
        {"role": "user", "content": "Explain inference in one sentence."}
    ],
    extra_body={"service_tier": "default"},
)

print(message.content[0].text)
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://api.gradiated.com",
  apiKey: process.env.GRADIATED_API_KEY,
});

const message = await client.messages.create({
  model: "YOUR_MODEL",
  max_tokens: 256,
  messages: [{ role: "user", content: "Explain inference in one sentence." }],
  service_tier: "default",
});

console.log(message.content[0].text);
```

  </DocsCodeTab>
</DocsCodeTabs>

Replace `YOUR_MODEL` with a chat model from [models and pricing](/docs/models-pricing/). Decision models accept only [SystemOne](/docs/systemone-sdk/) requests.

The example uses the `default` service tier. Change to `flex` for background agents where latency is less important, or `fast` when you want faster responses and are happy to pay more.

## Streaming

Use the streaming helper to process text as the model generates it.

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
with client.messages.stream(
    model="YOUR_MODEL",
    max_tokens=256,
    messages=[{"role": "user", "content": "Write one short sentence."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
const stream = client.messages
  .stream({
    model: "YOUR_MODEL",
    max_tokens: 256,
    messages: [{ role: "user", content: "Write one short sentence." }],
  })
  .on("text", (text) => process.stdout.write(text));

await stream.finalMessage();
```

  </DocsCodeTab>
</DocsCodeTabs>

Check [models and pricing](/docs/models-pricing/) to confirm that the model supports streaming.

## Tool calling

Send tool definitions with the request. The model can then ask your application to run one of them.

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
message = client.messages.create(
    model="YOUR_MODEL",
    max_tokens=256,
    messages=[{"role": "user", "content": "What is the weather in Warsaw?"}],
    tools=[{
        "name": "get_weather",
        "description": "Get the current weather for a city.",
        "input_schema": {
            "type": "object",
            "properties": {"city": {"type": "string"}},
            "required": ["city"],
        },
    }],
)

tool_uses = [block for block in message.content if block.type == "tool_use"]
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
const message = await client.messages.create({
  model: "YOUR_MODEL",
  max_tokens: 256,
  messages: [{ role: "user", content: "What is the weather in Warsaw?" }],
  tools: [
    {
      name: "get_weather",
      description: "Get the current weather for a city.",
      input_schema: {
        type: "object",
        properties: { city: { type: "string" } },
        required: ["city"],
      },
    },
  ],
});

const toolUses = message.content.filter((block) => block.type === "tool_use");
```

  </DocsCodeTab>
</DocsCodeTabs>

Your application must validate the tool input and run the function. Send the result in a `tool_result` block when you continue the conversation.
