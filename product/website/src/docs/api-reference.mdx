# API reference

<DocsLead>Use inference endpoints for model requests.</DocsLead>

## Inference endpoints

| Method | Path                | Purpose                                  |
| ------ | ------------------- | ---------------------------------------- |
| `GET`  | `/models`           | List accessible models.                  |
| `POST` | `/chat/completions` | Send an OpenAI Chat Completions request. |
| `POST` | `/v1/responses`     | Send an OpenAI Responses request.        |
| `POST` | `/v1/messages`      | Send an Anthropic Messages request.      |

Send the API key as a bearer token:

```http
Authorization: Bearer grad_...
```
