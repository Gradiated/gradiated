## What you need

You need a Gradiated account, a workspace API key, and a model ID.

Create API keys in the [Gradiated console](https://console.gradiated.com). A key belongs to one workspace. The console shows the secret only when you create the key. Store it in an environment variable.

The inference API is available at `https://api.gradiated.com`. It accepts requests at `/v1/chat/completions` and uses the standard `Authorization: Bearer` header.

## The request path

Every request follows the same path:

1. Pick a model ID from the model catalog.
2. Send a chat completion request to Gradiated.
3. Set `stream` to `true` when you want server-sent events.
4. Read usage from the response.

Gradiated routes each request to the selected model. The API applies the model's context and output limits. The API also checks workspace access and billing capacity before it starts inference.

## Keep your key private

Do not put an API key in a browser bundle, a public repository, an `opencode.json` file, or a project config file. Use an environment variable or a local credential store.
