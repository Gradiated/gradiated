# Gradiated API

<DocsLead>Connect your existing OpenAI or Anthropic client to affordable inference.</DocsLead>

## Connect

Every request needs three values:

- Base URL: `https://api.gradiated.com`
- API key: a Gradiated key sent from your server
- Model: a model from [models and pricing](/docs/models-pricing/)

You can use the official [OpenAI SDK](/docs/openai-sdk/) or [Anthropic SDK](/docs/anthropic-sdk/), or call the HTTP endpoints directly. You won't need to make any code changes to use our inference. The [quickstart](/docs/quickstart/) includes working examples for Python, Node, and cURL.

For decision requests with linden-1, use the [SystemOne SDK](/docs/systemone-sdk/) with Python, Node, or cURL. The guide covers the TypeSafe SDK used for Jev and the exact linden-1 model to select on Gradiated. linden-1 supports only the `default` service tier.

## Service tiers

Gradiated allows you to select the trade-off you want between performance and cost. You can use the `service_tier` parameter for this.

Use `fast` for interactive workloads, `default` for general production traffic, or `flex` for background agents.

```json
{
  "model": "YOUR_MODEL",
  "service_tier": "default"
}
```

See [service tiers](/docs/service-tiers/) for prices and complete SDK examples.

## Training

Train routers, classifiers, reward models, and fine-tuned or RL-tuned LLMs from production traces or live environments using the `grad` CLI and SDKs. Pick a built-in [recipe](/docs/training/recipes/) with smart defaults and typed config, or write a [custom Python loop](/docs/training/custom-loops/) directly against `Trainer` and `Artifact` primitives.
