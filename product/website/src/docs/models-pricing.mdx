## Supported models

<DocsModelCatalog />

Use `GET https://api.gradiated.com/api/v1/models` when your application needs the catalog. This endpoint is public.

The response also contains output limits, streaming support, and supported parameters.

## Model selection

Gradiated runs the model you name. It does not replace the model with an alias or fallback.

If that model is temporarily unavailable, the API returns `model_unavailable`. Retry later or choose another model.
