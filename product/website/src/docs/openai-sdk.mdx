## Chat Completions

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
)

response = client.chat.completions.create(
    model="YOUR_MODEL",
    messages=[
        {"role": "user", "content": "Explain inference in one sentence."}
    ],
    extra_body={"service_tier": "default"},
)

print(response.choices[0].message.content)
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.gradiated.com",
  apiKey: process.env.GRADIATED_API_KEY,
});

const response = await client.chat.completions.create({
  model: "YOUR_MODEL",
  messages: [{ role: "user", content: "Explain inference in one sentence." }],
  service_tier: "default",
});

console.log(response.choices[0].message.content);
```

  </DocsCodeTab>
</DocsCodeTabs>

Replace `YOUR_MODEL` with a model from [models and pricing](/docs/models-pricing/).

The example uses the `default` service tier. Change to `flex` for background agents where latency is less important, or `fast` when you want faster responses and are happy to pay more.

## Streaming

Set `stream` to `true` to process output as the model generates it.

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
stream = client.chat.completions.create(
    model="YOUR_MODEL",
    messages=[{"role": "user", "content": "Write one short sentence."}],
    stream=True,
)

for chunk in stream:
    if not chunk.choices:
        continue
    text = chunk.choices[0].delta.content
    if text:
        print(text, end="", flush=True)
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
const stream = await client.chat.completions.create({
  model: "YOUR_MODEL",
  messages: [{ role: "user", content: "Write one short sentence." }],
  stream: true,
});

for await (const chunk of stream) {
  const text = chunk.choices[0]?.delta?.content;
  if (text) process.stdout.write(text);
}
```

  </DocsCodeTab>
</DocsCodeTabs>

Check [models and pricing](/docs/models-pricing/) to confirm that the model supports streaming.

## Tool calling

Send function definitions with the request. The model can then ask your application to run one of them.

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
response = client.chat.completions.create(
    model="YOUR_MODEL",
    messages=[{"role": "user", "content": "What is the weather in Warsaw?"}],
    tools=[{
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a city.",
            "parameters": {
                "type": "object",
                "properties": {"city": {"type": "string"}},
                "required": ["city"],
            },
        },
    }],
)

tool_calls = response.choices[0].message.tool_calls
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
const response = await client.chat.completions.create({
  model: "YOUR_MODEL",
  messages: [{ role: "user", content: "What is the weather in Warsaw?" }],
  tools: [
    {
      type: "function",
      function: {
        name: "get_weather",
        description: "Get the current weather for a city.",
        parameters: {
          type: "object",
          properties: { city: { type: "string" } },
          required: ["city"],
        },
      },
    },
  ],
});

const toolCalls = response.choices[0].message.tool_calls;
```

  </DocsCodeTab>
</DocsCodeTabs>

Your application must validate the arguments and run the function. Gradiated does not run it.
