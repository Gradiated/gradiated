# Parameters and model support

<DocsLead>Each model has its own context limit and supported parameters. Check the catalog before you build a request.</DocsLead>

The [model catalog](/docs/models-pricing/) lists `supported_parameters` and `passthrough_parameters` for every model.

## Common parameters

| Parameter      | Purpose                                   |
| -------------- | ----------------------------------------- |
| `max_tokens`   | Limit the number of generated tokens.     |
| `temperature`  | Adjust sampling variation.                |
| `stream`       | Receive output as the model generates it. |
| `tools`        | Provide the tools available to the model. |
| `service_tier` | Choose `fast`, `default`, or `flex`.      |

Gradiated rejects an unsupported parameter instead of ignoring it. The response uses the code `unsupported_parameter` and names the parameter when possible.

## Context limits

Messages, tool definitions, and the requested output must fit within the model context window. If the API returns `context_length_exceeded`, reduce the input or `max_tokens`.
