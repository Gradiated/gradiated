# Quickstart

<DocsLead>Send your first request with the OpenAI SDK, Anthropic SDK, or cURL. You need a Gradiated API key and the model you'd like to use.</DocsLead>

## Send a request

<DocsCodeVariants>
  <DocsCodeVariant label="OpenAI SDK">

```python
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
)

response = client.chat.completions.create(
    model="YOUR_MODEL",
    messages=[{"role": "user", "content": "Hello from Gradiated."}],
)

print(response.choices[0].message.content)
```

```python
from anthropic import Anthropic
import os

client = Anthropic(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
)

message = client.messages.create(
    model="YOUR_MODEL",
    max_tokens=256,
    messages=[{"role": "user", "content": "Hello from Gradiated."}],
)

print(message.content[0].text)
```

## Configuration

Both SDKs use `https://api.gradiated.com` as the base URL. Choose a chat model from [models and pricing](/docs/models-pricing/) and replace `YOUR_MODEL` with your choice.

Store the key as an environment variable named `GRADIATED_API_KEY` in your server environment. Never include it in browser or mobile application code.
