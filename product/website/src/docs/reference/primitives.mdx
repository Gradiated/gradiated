# Primitives reference

<DocsLead>Schemas, field definitions, and enums for the five core training and serving primitives (`Trajectory`, `Datum`, `ModelSpec`, `Artifact`, and `Endpoint`).</DocsLead>

These schemas mirror the OpenAPI 3.1 contract (`spec/openapi.yaml`) used across the server, CLI, and generated Python, TypeScript, Go, and Rust SDKs. See [API reference](/docs/api-reference/) for HTTP routes.

## `Trajectory` (`grad.trajectory/1`)

Universal model-agnostic record for production traces, supervised `(input, expected_output)` pairs, multimodal inputs, and multi-turn RL rollouts. Managed [recipes](/docs/training/recipes/) operate directly on `Trajectory` records with no pre-tokenization.

```json
{
  "schema": "grad.trajectory/1",
  "id": "traj_9f82a1",
  "session_id": "sess_42",
  "group_id": "grp_prompt_42",
  "role": "rollout",
  "source": "otel",
  "input": {
    "messages": [{ "role": "user", "content": "Refund order #8821" }],
    "tools": [{ "name": "issue_refund" }],
    "media": [{ "kind": "image", "ref": "s3://bucket/screenshot.png" }],
    "features": { "customer_tier": "enterprise", "turn_index": 0 },
    "payload": null
  },
  "output": {
    "turns": [{ "role": "assistant", "content": "Refund issued." }],
    "token_ids": [151644, 8948],
    "turn_ids": [0, 0],
    "response_offset": 1,
    "sampling_logprobs": [0.0, -0.12],
    "loss_mask": [0.0, 1.0],
    "weight_version": "v12",
    "payload": null
  },
  "expected_output": null,
  "scores": { "task_success": 1.0, "user_thumbs": 1.0 },
  "metrics": {
    "cost_usd": 0.01105,
    "latency_ms": 4210,
    "input_tokens": 1820,
    "output_tokens": 240
  },
  "metadata": {
    "endpoint": "support-router",
    "artifact": "support-router@v12",
    "inference_id": "inf_01J9Y",
    "propensity": 0.10,
    "is_probe": true
  },
  "timestamp": "2026-11-25T18:00:05Z"
}
```

| Field | Type | Purpose |
| --- | --- | --- |
| `session_id` | `string \| null` | Groups multi-turn conversations so train/eval splits never leak turns across splits. |
| `group_id` | `string \| null` | Keeps paired or grouped examples atomic across splits and microbatches (DPO, GRPO, InfoNCE, rerankers). |
| `role` | `string \| null` | `chosen`, `rejected`, `anchor`, `positive`, `negative`, `desirable`, `undesirable`, or `rollout`. |
| `input` | `object` | `messages[]`, `tools[]`, `media[]` (`{ kind, ref }`), `features{}` (tabular signals), and optional arbitrary `payload`. |
| `output` | `object` | `turns[]`, optional `payload`, plus token-aligned RL fields (`token_ids`, `turn_ids`, `response_offset`, `sampling_logprobs`, `loss_mask`, `weight_version`) filled by `Artifact.sample()`. |
| `expected_output` | `object \| null` | Gold correction or ground-truth label (`{ label }` or `{ content }`) used by `sft` and `classifier` recipes. |
| `scores` | `Record<string, number>` | Named scalar outcomes (`task_success`, `tests_passed`, `reward`, etc.). |
| `metrics` | `Record<string, number>` | Request telemetry (`cost_usd`, `latency_ms`, `input_tokens`, `output_tokens`). |
| `metadata` | `Record<string, any>` | Serving provenance (`endpoint`, `artifact`, `inference_id`, `model`, `propensity`, `is_probe`). |

### SDK helpers on `Trajectory`

- `traj.append_env_tokens(tokens, turn_id)` appends tool or environment observations with `loss_mask = 0.0` and `sampling_logprobs = 0.0` in lockstep.
- `traj.to_datum(advantage=..., advantages=..., ref_logprobs=..., teacher_topk=..., scalar=...)` converts a `Trajectory` into a tokenizer-aligned `Datum`.

## `Datum` & 1:1 token alignment

Used in [custom loops](/docs/training/custom-loops/). For any `model_input.tokens` array of length `T`, every per-token array (`loss_mask`, `sampling_logprobs`, `ref_logprobs`, `advantages`, and `forward().logprobs`) has exact length `T` where index `i` predicts `tokens[i]` given `tokens[:i]` and index `0` is `0.0`.

```json
{
  "group_id": "grp_prompt_42",
  "role": "rollout",
  "model_input": {
    "tokens": [151644, 8948, 220, 15],
    "turn_ids": [0, 0, 1, 1],
    "media": [{ "kind": "image", "ref": "s3://bucket/screen.png" }],
    "embedding": null,
    "features": { "turn_index": 0 }
  },
  "targets": {
    "loss_mask": [0.0, 0.0, 1.0, 1.0],
    "response_offset": 2,
    "positions": null,
    "labels": null,
    "label": null,
    "scalar": null,
    "sampling_logprobs": [0.0, 0.0, -0.41, -0.12],
    "ref_logprobs": [0.0, 0.0, -0.39, -0.15],
    "teacher_topk": null,
    "advantages": [0.0, 0.0, 1.12, 1.12]
  }
}
```

## `ModelSpec` & built-in losses

| Field | Supported values |
| --- | --- |
| `adapter` | `frozen_head`, `lora`, `dora`, `qlora_nf4`, `prefix_kv`, `loreft`, `eagle3_draft`, `full` |
| `train_mode` | `frozen_head`, `lora`, `prefix_kv`, `loreft`, `partial_unfreeze`, `full` |
| `pool` | `last`, `mean`, `mean_last`, `none` |
| `heads` | Map of `{ name: { dim, token_level?: bool, trainable?: bool } }` |
| `init_from` | Optional `Artifact` or `StateCheckpoint` ID |

Built-in `forward_backward` losses: `cross_entropy`, `bce_logits`, `l2_logistic`, `dpo`, `grpo`, `cispo`, `reverse_kl_distill`, `topk_kl_distill`, `infonce`, `bce_sparse_positions`. Custom objectives run via `trainer.forward_backward_custom()`.

## `Artifact` (`.grad`) & `Endpoint` (`grad.endpoint/1`)

- An **`Artifact`** is always **one** immutable model (`name@version`, base model ID, or ephemeral `trainer.snapshot()`), containing `manifest.json`, runtime weight files, and `eval_report.json`.
- An **`Endpoint`** is a mutable production slot over **one or more** artifacts supporting `active`, `canary`, and `shadow` routing and seven strategies: `direct`, `sla_lagrangian`, `confidence_fallback`, `syntax_fallback`, `cascade`, `best_of_n` / `majority_vote`, and `budget_forcing`. See [Artifacts and endpoints](/docs/training/endpoints/).
