# Primitives reference

<DocsLead>Schemas, dataclasses, and extensible interfaces for the five core training and serving primitives (`Trajectory`, `Environment`, `Trainer`, `Artifact`, and `Endpoint`).</DocsLead>

These wire schemas mirror the OpenAPI 3.1 contract (`spec/openapi.yaml`) used across the server, CLI, and Python, TypeScript, Go, and Rust SDKs. See [API reference](/docs/api-reference/) for HTTP routes.

## `Trajectory` (`grad.trajectory/1`)

Universal model-agnostic record for production traces, supervised `(input, expected_output)` pairs, multimodal inputs, and multi-turn RL rollouts.

```json
{
  "schema": "grad.trajectory/1",
  "id": "traj_9f82a1",
  "session_id": "sess_42",
  "group_id": "grp_prompt_42",
  "role": "rollout",
  "source": "otel",
  "input": {
    "messages": [{ "role": "user", "content": "Refund order #8821" }],
    "tools": [{ "name": "issue_refund" }],
    "media": [{ "kind": "image", "ref": "s3://bucket/screenshot.png" }],
    "features": { "customer_tier": "enterprise", "turn_index": 0 },
    "payload": null
  },
  "output": {
    "turns": [{ "role": "assistant", "content": "Refund issued." }],
    "token_ids": [151644, 8948],
    "turn_ids": [0, 0],
    "response_offset": 1,
    "sampling_logprobs": [0.0, -0.12],
    "loss_mask": [0.0, 1.0],
    "weight_version": "v12",
    "payload": null
  },
  "expected_output": null,
  "scores": { "task_success": 1.0, "user_thumbs": 1.0 },
  "metrics": {
    "cost_usd": 0.01105,
    "latency_ms": 4210,
    "input_tokens": 1820,
    "output_tokens": 240
  },
  "metadata": {
    "endpoint": "support-router",
    "artifact": "support-router@v12",
    "inference_id": "inf_01J9Y",
    "propensity": 0.10,
    "is_probe": true
  },
  "timestamp": "2026-11-25T18:00:05Z"
}
```

| Field | Type | Purpose |
| --- | --- | --- |
| `session_id` | `string \| null` | Groups multi-turn conversations so train/eval splits never leak turns across splits. |
| `group_id` | `string \| null` | Keeps paired or grouped examples atomic across splits and microbatches (DPO, GRPO, InfoNCE, rerankers). |
| `role` | `string \| null` | `chosen`, `rejected`, `anchor`, `positive`, `negative`, `desirable`, `undesirable`, or `rollout`. |
| `input` | `object` | `messages[]`, `tools[]`, `media[]` (`{ kind, ref }`), `features{}` (tabular signals), and optional arbitrary `payload`. |
| `output` | `object` | `turns[]`, optional `payload`, plus token-aligned RL fields (`token_ids`, `turn_ids`, `response_offset`, `sampling_logprobs`, `loss_mask`, `weight_version`) filled by `Artifact.sample()`. |
| `expected_output` | `object \| null` | Gold correction or ground-truth label (`{ label }` or `{ content }`) used by `SFTRecipe` and `ClassifierRecipe`. |
| `scores` | `Record<string, number>` | Named scalar outcomes (`task_success`, `tests_passed`, `reward`, etc.). |
| `metrics` | `Record<string, number>` | Request telemetry (`cost_usd`, `latency_ms`, `input_tokens`, `output_tokens`). |
| `metadata` | `Record<string, any>` | Serving provenance (`endpoint`, `artifact`, `inference_id`, `model`, `propensity`, `is_probe`). |

### SDK helpers on `Trajectory` & custom loops

- `traj.append_env_tokens(tokens, turn_id)` appends tool or environment observations with `loss_mask = 0.0` and `sampling_logprobs = 0.0` in lockstep.
- `traj.slice_prefix(end_idx)` extracts an immutable prefix trajectory for Monte Carlo step branching (e.g. VinePPO).
- `traj.to_datum(advantage=..., advantages=..., ref_logprobs=..., teacher_topk=..., scalar=..., group_id=..., role=...)` converts a `Trajectory` into a tokenizer-aligned `Datum`.
- `grad.group_datums(groups, rewards=..., advantage=advantages.GroupStd(), skip_zero_var=True, ref_logprobs=...)` normalizes RL rollout groups into advantage-annotated `Datum`s using any `AdvantageEstimator` (`advantages.GroupStd`, `advantages.GroupMean`, `advantages.RLOO`, or a custom callable).
- `grad.by_group(datums, out)` and `grad.masked_mean(x, mask)` group `CustomLoss` outputs safely by `group_id` and `role` (`chosen`/`rejected`, `anchor`/`positive`/`negative`) using pre-tensorized `out.masks` *(with `mask[0] == 0.0` guaranteed)*, `out.sampling_logprobs`, `out.ref_logprobs`, `out.advantages`, `out.turn_ids`, and auto-batch-fetched `out.teacher_topk_logprobs`.

## `Datum` & 1:1 token alignment

Used inside [custom loops](/docs/training/custom-loops/). For any `model_input.tokens` array of length `T`, every per-token array (`loss_mask`, `sampling_logprobs`, `ref_logprobs`, `advantages`, and `out.logprobs`) has exact length `T` where index `i` predicts `tokens[i]` given `tokens[:i]` and index `0` is `0.0`.

```json
{
  "group_id": "grp_prompt_42",
  "role": "rollout",
  "model_input": {
    "tokens": [151644, 8948, 220, 15],
    "turn_ids": [0, 0, 1, 1],
    "media": [{ "kind": "image", "ref": "s3://bucket/screen.png" }],
    "embedding": null,
    "features": { "turn_index": 0 }
  },
  "targets": {
    "loss_mask": [0.0, 0.0, 1.0, 1.0],
    "response_offset": 2,
    "positions": null,
    "labels": null,
    "label": null,
    "scalar": null,
    "sampling_logprobs": [0.0, 0.0, -0.41, -0.12],
    "ref_logprobs": [0.0, 0.0, -0.39, -0.15],
    "teacher_topk": null,
    "advantages": [0.0, 0.0, 1.12, 1.12]
  }
}
```

## Typed SDK entities & interfaces (`grad.*`)

The SDK passes strict domain entities (`Dataset`, `Model`, `Artifact`, `Endpoint`, `Secret`, `Pool`) rather than raw strings, alongside **value specs** (pure configuration) and **extensible base classes** (swappable algorithms):

| Category | Kind | Classes |
| --- | --- | --- |
| **Domain Entities** | First-class resource handles & value refs | `Dataset` (`client.datasets.get/create`, `.push()`, `.import_file()`, `.filter()`, `.add_source()`), `Model("...")` / `client.models.get(...)`, `Artifact(Model)` (`run.artifact`, `client.artifacts.get(...)`), `Endpoint` (`client.endpoints.get/create`), `Secret` (`client.secrets.get(...)`), `Pool` (`client.pools.get(...)`) |
| **Adapters & Pooling** | `@dataclass(frozen=True)` | `adapters.FrozenHead`, `adapters.LoRA(rank, merge_on_export=False)`, `adapters.DoRA`, `adapters.QLoRA`, `adapters.PrefixKV`, `adapters.LoReFT`, `adapters.Eagle3Draft`, `adapters.PartialUnfreeze`, `adapters.Full`; `pooling.Mean`, `pooling.Last`, `pooling.PerToken` |
| **Heads** | `@dataclass(frozen=True)` | `heads.Linear(dim, token_level=False, trainable=True)` |
| **Optimizers** | `@dataclass(frozen=True)` | `optim.AdamW`, `optim.Muon`, `optim.SGD`, `optim.ParamGroup(target=...)`, `optim.WeightAnchor` |
| **Losses & Advantages** | Extensible `Loss` / `AdvantageEstimator` | Built-in GPU kernels (`losses.CrossEntropy`, `losses.BCEWithLogits`, `losses.OrdinalBCE`, `losses.DPO`, `losses.ImportanceSampling`, `losses.GRPO`, `losses.CISPO`, `losses.ReverseKLDistill`, `losses.TopKKLDistill`, `losses.InfoNCE`, `losses.BCESparsePositions`), user `losses.CustomLoss` subclasses, and `advantages.GroupStd`, `advantages.GroupMean`, `advantages.RLOO` |
| **Solvers, Splitters, Filters & Mergers** | Extensible interfaces | `solvers.DualHeadKernelLBFGS`, `solvers.MeanDiffSteering`, `splits.BySession`, `splits.ByGroup`, `splits.Random`, `filters.MinScore` (via `dataset.filter(...)`), `mergers.TIES`, `mergers.Linear`, `mergers.DARE`, `mergers.SLERP` |
| **Rubrics & Validators** | Typed scorers & validators | `Rubric`, `Scorer`, `StatefulScorer`, `GroupScorer`, `WebhookRubric`; `validators.TypeScriptAST`, `validators.JSONSchema`, `validators.SQL` (or any `Callable[[str], bool]`) |
| **Recipes** | Subclassable `Recipe` + chained `Run` | `RouterRecipe`, `ClassifierRecipe`, `SFTRecipe`, `DPORecipe`, `GRPORecipe`, `DistillRecipe(rollout=OnPolicy/OffPolicy)`, `CartridgeRecipe(context=Context.from_uri(...))` — chain via `run.then(...)` or pending `run.artifact`, stream via `run.metrics()` |
| **Endpoint Strategies** | Extensible `Strategy` base class | `strategies.Direct`, `strategies.SLALagrangian`, `strategies.ConfidenceFallback`, `strategies.SyntaxFallback`, `strategies.Cascade`, `strategies.BestOfN`, `strategies.MajorityVote`, `strategies.BudgetForcing` (configurable or subclassable) |

- `Artifact` subclasses `Model`, so `model=` on any `Recipe`, `Trainer`, or `Strategy` accepts a pure `Model("Qwen/Qwen3-8B")` ref, a live `client.models.get(...)` handle, a completed `Artifact`, or a pending `run.artifact` from an in-flight run.
- `client.trainers.resume(ckpt)` restores both weights and optimizer moments from a `trainer.save_state()` checkpoint.

## `Model`, `Artifact` (`.grad`) & `Endpoint` (`grad.endpoint/1`)

- A **`Model`** (`Model("Qwen/Qwen3-8B")` pure value ref or `client.models.get("Qwen/Qwen3-8B")` live handle) represents an immutable base or catalog model; an **`Artifact(Model)`** (`name@version` or ephemeral `trainer.snapshot()`) subclasses `Model` and adds `manifest.json`, trained runtime weights, `eval_report.json`, and `.deploy()`.
- `Model.sample()` / `Artifact.sample()` returns 1:1 token-aligned `Trajectory` rollouts and accepts `n`, `temperature`, `top_p`, `max_new_tokens`, `stop` *(string or token-ID sequences)*, `seed`, `response_format` (`ResponseFormat.json_schema(...)`), `resume_from` *(optional `prompts=None` when resuming)*, and `append_env_tokens`. Use `artifact.openai_client()` to drive an existing OpenAI-SDK agent against a live snapshot while recording aligned trajectories automatically.
- `Model.score_logprobs()` / `Artifact.score_logprobs()` returns a typed `ScoreResult` (`.response_logprobs`, `.aligned_logprobs`, `.topk_refs`, `.candidate_logprobs`, `.layer_refs`) for full sequences, `Trajectory` objects, or `(prefix_tokens, response_tokens)` pairs.
- `Model.infer()` / `Artifact.infer_batch()` accept `ModelInput` or `Trajectory` lists and return typed `InferResult` objects (`.logits`, `.heads`).
- `Model.tokenize()` renders chat templates server-side (`messages`, `tools`, `media`, optional `return_loss_mask=True`); `Model.to_datum(...)` wraps tokenization directly into a `Datum`.
- An **`Endpoint`** is a mutable production slot over **one or more** artifacts retrieved via `client.endpoints.get(slug)` or returned by `client.endpoints.create(...)` / `artifact.deploy()` / `run.deploy()`. See [Artifacts and endpoints](/docs/training/endpoints/).
