# Stream a response

<DocsLead>
  Show output as the model generates it. This reduces the time before a user
  sees the first text.
</DocsLead>

<DocsCodeVariants>
  <DocsCodeVariant label="OpenAI SDK">

```python
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
)

stream = client.chat.completions.create(
    model="YOUR_MODEL_ID",
    messages=[{"role": "user", "content": "Write one short sentence."}],
    stream=True,
)

for chunk in stream:
    text = chunk.choices[0].delta.content
    if text:
        print(text, end="", flush=True)
```

  <DocsCodeVariant label="Anthropic SDK">

```python
from anthropic import Anthropic
import os

client = Anthropic(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
)

with client.messages.stream(
    model="YOUR_MODEL_ID",
    max_tokens=256,
    messages=[{"role": "user", "content": "Write one short sentence."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

  <DocsCodeVariant label="OpenAI SDK">

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.gradiated.com",
  apiKey: process.env.GRADIATED_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "YOUR_MODEL_ID",
  messages: [{ role: "user", content: "Write one short sentence." }],
  stream: true,
});

for await (const chunk of stream) {
  const text = chunk.choices[0]?.delta?.content;
  if (text) process.stdout.write(text);
}
```

  <DocsCodeVariant label="Anthropic SDK">

```javascript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://api.gradiated.com",
  apiKey: process.env.GRADIATED_API_KEY,
});

const stream = client.messages
  .stream({
    model: "YOUR_MODEL_ID",
    max_tokens: 256,
    messages: [{ role: "user", content: "Write one short sentence." }],
  })
  .on("text", (text) => process.stdout.write(text));

await stream.finalMessage();
```

  <DocsCodeTab label="cURL">

```sh
curl -N https://api.gradiated.com/chat/completions \
  -H "Authorization: Bearer $GRADIATED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_MODEL_ID",
    "messages": [{"role": "user", "content": "Write one short sentence."}],
    "stream": true
  }'
```

  </DocsCodeTab>

The SDK closes the iterator when the stream ends. For cURL, keep the connection open until the stream sends `[DONE]` or an error closes it.

The model catalog states whether a model supports streaming.
