# SystemOne SDK

<DocsLead>Use the TypeSafe SDK to ask linden-1 for decisions. Set your Gradiated base URL, API key, and model, then send a state and named questions.</DocsLead>

linden-1 is Gradiated's open decision model, served through the native SystemOne API. If you already use TypeSafe's SDK for Jev, use the same client with `gradiated/linden-1` on Gradiated. This selects linden-1; `jev-latest` is not a Gradiated model alias.

## Make a decision

Send the information to evaluate as `state`, and the decision to make as a named question. State can be text, a JSON object, or an array.

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
import os
from typesafe_sdk import Choice, TypeSafeClient

with TypeSafeClient(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
    model="gradiated/linden-1",
) as client:
    response = client.system_one(
        state={"ticket": "I was charged twice. Please fix this today."},
        questions={
            "category": Choice(
                instructions="Choose the department for this ticket.",
                criteria={
                    "billing": "Charges or payments",
                    "technical": "Something is broken",
                    "other": "Anything else",
                },
            ),
        },
    )

print(response.choices["category"].choice)
print(response.choices["category"].probabilities)
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

## Ask multiple questions

Questions in one request share the same state. Use `Noul` for a yes/no probability and `Score` for an ordered rating.

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
import os
from typesafe_sdk import Noul, Score, TypeSafeClient

with TypeSafeClient(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
    model="gradiated/linden-1",
) as client:
    response = client.system_one(
        state={"ticket": "I was charged twice. Please fix this today."},
        questions={
            "billing": Noul(instructions="Is this about a payment problem?"),
            "urgency": Score(
                instructions="Rate how urgently this ticket needs attention.",
                criteria=["Can wait", "Needs attention today", "Needs immediate attention"],
            ),
        },
    )

print(response.nouls["billing"].noul)
print(response.scores["urgency"].score)
```

  </DocsCodeTab>
  <DocsCodeTab label="Node">

```javascript
import { noul, score, TypeSafeClient } from "@typesafe-ai/sdk";

const client = new TypeSafeClient({
  baseURL: "https://api.gradiated.com",
  apiKey: process.env.GRADIATED_API_KEY,
  defaultModel: "gradiated/linden-1",
});

const response = await client.systemOne({
  state: { ticket: "I was charged twice. Please fix this today." },
  questions: {
    billing: noul("Is this about a payment problem?"),
    urgency: score("Rate how urgently this ticket needs attention.", ["Can wait", "Needs attention today", "Needs immediate attention"]),
  },
});

console.log(response.answers.billing.noul);
console.log(response.answers.urgency.score);
```

  </DocsCodeTab>
</DocsCodeTabs>

| Question | Result                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `choice` | The selected option, probabilities for each option, and confidence.                                                            |
| `noul`   | A probability of “yes” from 0 to 1. Apply your own decision threshold.                                                         |
| `score`  | An expected score across zero-indexed criteria. The three-level example returns a number from 0 to 2, which can be fractional. |

## Supported requests

linden-1 accepts 1–1,024 named questions per request. A choice has 1–255 options, as an object of descriptions or a list of option names, and a score 1–255 ordered criteria; a single option or level is answered with certainty. Instructions are optional: a question without them is asked through its criteria alone. States are text, JSON or a text-only chat; images and other media are not supported. The hosted runtime limits bodies to 1 MiB and each question's prompt, including the state, to 32,768 tokens.

Use the native SystemOne endpoint for linden-1. It returns all answers in one response, with no streaming or text generation parameters such as `max_tokens` or `temperature`. Only the `default` service tier is supported; omit `service_tier` to use it.

Usage counts the tokens linden-1 reads: the prompt shared by all questions once, plus each question's own part. A request of up to about 3,000 tokens is read twice, so it counts roughly twice its length. Generated output tokens are zero. See [errors and retries](/docs/errors/) for handling rejected requests and rate limits.
