# Artifacts

<DocsLead>Every training run saves a versioned `.grad` artifact with your trained weights and evaluation results.</DocsLead>

An **`Artifact`** is a saved, versioned model produced by a training run (`fast-diff-merge@2026-11-26-1`). Artifacts are never overwritten: every new run writes a new version with its weights (`adapter_config.json` and `adapter_model.safetensors` for LoRA, or full Safetensors weights) alongside its held-out `eval_report.json`.

## Inspect and test an artifact

Load any saved artifact with `client.artifacts.get(...)` (or use `run.artifact` straight from a finished run). Check its held-out `eval_report` or score a batch of examples offline before deploying:

```python
from grad import Grad, Record

client = Grad()
art = client.artifacts.get("fast-diff-merge@2026-11-26-1")

print(art.eval_report)

preds = art.infer_batch([
    Record(messages=[{"role": "user", "content": "Merge these two diffs into one patch: ..."}]),
])
print(preds[0].text)
```

You can pass any trained `Artifact` anywhere a model name is accepted:

- **Start the next training stage:** `DPORecipe(model=sft.artifact, ...)` or `GRPORecipe(model=sft.artifact, ...)`.
- **Use as a judge:** `Judge(name="sql_ok", model=reward_model_artifact)`.
- **Use as a distillation teacher:** `DistillRecipe(model="qwen/qwen3-4b", teacher=teacher_artifact)`.

## Which checkpoint becomes the artifact

Managed runs checkpoint automatically as they train (every 10% of steps, and at least every 20 steps), including optimizer state, and evaluate each checkpoint on the held-out split. `run.artifact` is the checkpoint with the best eval score by default. Pass `select="last"` on the recipe to keep the final checkpoint instead, for example when you've added your own `evals=` and want to choose by hand:

```python
from grad import Grad

client = Grad()
run = client.runs.get("run_01J9Z2")

for ckpt in run.checkpoints():
    print(ckpt.step, ckpt.eval_score, ckpt.expires_at)

art = run.checkpoints()[-1].promote(name="fast-diff-merge")  # save a checkpoint as a versioned Artifact
```

Checkpoints are kept for 30 days. Artifacts, including promoted checkpoints, are kept until you delete them. If a run stops early (a crash, a `max_cost_usd` budget, or a cancel), continue it from its latest checkpoint with `client.runs.resume("run_01J9Z2")`.

## Deploy on Gradiated Cloud or download weights

Every artifact can either be hosted directly on Gradiated Cloud (with canary rollouts and standard OpenAI / Anthropic / SystemOne SDK calls) or downloaded as standard weights to run on your own vLLM or SGLang servers:

<DocsCodeTabs>
  <DocsCodeTab label="Gradiated Cloud">

```python
from grad import Grad

client = Grad()

# Publish under your-org/fast-diff-merge (or roll out at 10% canary).
# From a finished run, `run.deploy(canary=0.10)` does the same.
client.artifacts.get("fast-diff-merge@2026-11-26-1").deploy(canary=0.10)
```

  </DocsCodeTab>
  <DocsCodeTab label="Self-host (vLLM / SGLang)">

```bash
# Download standard HuggingFace PEFT LoRA weights (or merged weights)
grad artifacts download fast-diff-merge@2026-11-26-1 --output ./fast-diff-merge

# Load straight into vLLM or SGLang:
vllm serve Qwen/Qwen3-8B --enable-lora --lora-modules fast-diff-merge=./fast-diff-merge
```

  </DocsCodeTab>
  <DocsCodeTab label="CLI">

```bash
grad artifacts inspect fast-diff-merge@2026-11-26-1 --json
grad deploy fast-diff-merge@2026-11-26-1 --canary 0.10
```

  </DocsCodeTab>
</DocsCodeTabs>

See [Deploying](/docs/training/deploying/) for canary rollouts, rollbacks, calling deployed models with the OpenAI / Anthropic / SystemOne SDKs, and self-hosting details.

## Merge artifacts without retraining

Combine two models trained from the same base (for example, a coding model and a reasoning model) into a single new `Artifact` with `client.artifacts.merge()`. Supported merge methods are `mergers.TIES`, `mergers.Linear`, `mergers.DARE`, and `mergers.SLERP`:

```python
from grad import Grad, mergers

client = Grad()
coder = client.artifacts.get("coder@v4")
reasoner = client.artifacts.get("reasoner@v2")

merged = client.artifacts.merge(
    name="assistant-merged",
    artifacts=[(coder, 0.6), (reasoner, 0.4)],
    merger=mergers.TIES(density=0.5),
)
```
