# Context Cartridges

<DocsLead>Turn a long, repeated prompt or doc set into a small add-on you don't have to resend on every request.</DocsLead>

If every request sends the same 30k–100k tokens of runbooks, product docs, or compliance rules, you pay to re-read that text over and over and wait longer for the first token.

## How a Cartridge works

A Cartridge shrinks a long static document into a tiny **precomputed memory** (a small KV cache) that plugs into a frozen base model:

1. **`context`** is the static document you want to compress (`Context.from_file(...)`, `Context.from_uri("s3://...")`, or `Context.from_text(...)`).
2. **`dataset`** is 500–2,000 real questions or tasks about that document (`input.messages` — no labeled answers needed).
3. **`num_tokens`** is how small to compress it (for example, `256` virtual tokens standing in for a 50,000-token manual, stored as `adapters.PrefixKV(num_tokens=256)` while the base model weights stay untouched).

During training, the model reads `context` + each question to see what it *would* answer with the full doc, and trains the Cartridge to give the same answer **without** sending `context` in the prompt. In production, one base model can swap different Cartridges per customer or repo on every request.

## Train a Cartridge (`CartridgeRecipe`)

`CartridgeRecipe` defaults `teacher=model` (override `teacher=` only if you want to distill from a larger model) and trains an `adapters.PrefixKV(num_tokens=...)` prefix automatically:

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Context, Grad, Model, losses, optim
from grad.recipes import CartridgeRecipe

client = Grad()
dataset = client.datasets.get("api-docs-qa-prompts")

recipe = CartridgeRecipe(
    model=Model("Qwen/Qwen3-8B"),
    context=Context.from_file("./api-docs-bundle.md"),  # or Context.from_uri("s3://...") / Context.from_text(...)
    num_tokens=256,
    loss=losses.TopKKLDistill(top_k=20),
    optimizer=optim.AdamW(lr=2e-2),
)

run = client.runs.create(dataset=dataset, name="api-docs-cartridge", recipe=recipe).wait()

print(run.artifact.id, run.eval_report)
```

```ts
import { Context, Grad, Model, losses, optim, recipes } from "@gradiated/grad";

const grad = new Grad();
const dataset = await grad.datasets.get("api-docs-qa-prompts");

const run = await grad.runs
  .create({
    dataset,
    name: "api-docs-cartridge",
    recipe: recipes.cartridge({
      model: new Model("Qwen/Qwen3-8B"),
      context: Context.fromFile("./api-docs-bundle.md"),
      numTokens: 256,
      loss: losses.topKKLDistill({ topK: 20 }),
      optimizer: optim.adamW({ lr: 2e-2 }),
    }),
  })
  .wait();

console.log(run.artifact.id, run.evalReport);
```

## Deploy and serve

Cartridges export as standard `.grad` artifacts (`prefix_kv.safetensors` + `base_model_ref`) and deploy onto any [`Endpoint`](/docs/training/endpoints/) identically to a LoRA adapter. Requests hit the endpoint with only the user question — no giant system prompt required:

```python
endpoint = run.deploy()
```

### Key parameters

- **`context`:** the static document(s) you want to compress (`Context.from_file(...)`, `Context.from_uri("s3://...")`, or `Context.from_text(...)`).
- **`num_tokens`:** how big the compressed Cartridge is — start with `128`–`256` for 10k–30k token manuals, or `512`–`1024` for 100k+ token docs. Compare answer accuracy in `eval_report` against the full-context model to pick the smallest size that holds quality.
- **`optim.AdamW(lr=...)`:** prefix KV tensors need a much higher learning rate (`1e-2`–`2e-2`) than LoRA adapters.

## When to use Cartridges vs. prompt distillation vs. RAG

- **Use `CartridgeRecipe`** when you serve many per-customer, per-tenant, or per-repo manuals against one shared base model and want to swap them per request without resending the full prompt.
- **Use prompt distillation (`DistillRecipe` + `context=`)** when you only have **one** global system prompt and want its knowledge baked straight into a fine-tuned model (see below).
- **Use RAG ([Embeddings](/docs/training/recipes/embeddings/))** when your knowledge base changes every minute or is millions of documents — Cartridges are best for static 10k–100k token docs that change daily or weekly.

### Baking one static prompt into LoRA instead

If you only have **one** static prompt and want a single fine-tuned checkpoint with no prefix-KV tensors at serving time, pass `context=` to [`DistillRecipe`](/docs/training/recipes/distillation/):

```python
from grad import Context, Model, adapters, losses
from grad.recipes import DistillRecipe, OnPolicy

recipe = DistillRecipe(
    model=Model("Qwen/Qwen3-8B"),
    teacher=Model("Qwen/Qwen3-8B"),
    context=Context.from_uri("s3://my-bucket/api-docs-bundle.md"),
    adapter=adapters.LoRA(rank=32),
    rollout=OnPolicy(max_new_tokens=512),
    loss=losses.TopKKLDistill(top_k=32),
)

run = client.runs.create(dataset=dataset, name="api-docs-prompt-distilled", recipe=recipe).wait()
```
