# Context Cartridges

<DocsLead>Turn a long, repeated prompt or doc set into a small add-on you don't have to resend on every request.</DocsLead>

If every request sends the same 30k–100k tokens of runbooks, product docs, or compliance rules, you pay to re-read that text over and over and wait longer for the first token.

## How a Cartridge works

A Cartridge shrinks a long system prompt or large block of background context into a tiny **precomputed memory** (a small KV cache) that plugs into your model:

1. **`context`** is the text you want the model to know without resending it every time: your entire system prompt, instructions and examples, or large chunks of docs and runbooks (`Context.from_text(...)`, `Context.from_file(...)`, or `Context.from_uri("s3://...")`).
2. **`dataset`** is 500–2,000 real questions or tasks that depend on that context (`input.messages`, with no labeled answers needed).
3. **`num_tokens`** is how small to compress that context (for example, `256` virtual tokens standing in for a 50,000-token prompt). Generally `256` works fine, and you can experiment with increasing it for very large contexts.

During training, the model reads `context` + each question to see what it *would* answer with the full text, and trains the Cartridge to give the same answer **without** sending `context` in the prompt.

## Train a Cartridge (`CartridgeRecipe`)

Pass your model, the `context` you want to compress, and a dataset of example prompts (you can also pass `teacher=` if you want to copy a larger model at the same time):

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Context, Grad, losses, optim
from grad.recipes import CartridgeRecipe

client = Grad()
dataset = client.datasets.get("api-docs-qa-prompts")

recipe = CartridgeRecipe(
    model="qwen/qwen3-8b",
    context=Context.from_file("./api-docs-bundle.md"),  # or Context.from_uri("s3://...") / Context.from_text(...)
    num_tokens=256,
    loss=losses.TopKKLDistill(top_k=20),
    optimizer=optim.AdamW(lr=2e-2),
)

run = client.runs.create(dataset=dataset, name="api-docs-cartridge", recipe=recipe).wait()

print(run.artifact.id, run.eval_report)
```

```ts
import { Context, Grad, losses, optim, recipes } from "@gradiated/grad";

const grad = new Grad();
const dataset = await grad.datasets.get("api-docs-qa-prompts");

const run = await grad.runs
  .create({
    dataset,
    name: "api-docs-cartridge",
    recipe: recipes.cartridge({
      model: "qwen/qwen3-8b",
      context: Context.fromFile("./api-docs-bundle.md"),
      numTokens: 256,
      loss: losses.topKKLDistill({ topK: 20 }),
      optimizer: optim.adamW({ lr: 2e-2 }),
    }),
  })
  .wait();

console.log(run.artifact.id, run.evalReport);
```

## Deploy and serve

Cartridges export as standard `.grad` artifacts (`prefix_kv.safetensors` + `base_model_ref`) and deploy onto any [`Endpoint`](/docs/training/endpoints/) identically to a LoRA adapter. Requests hit the endpoint with only the user question, with no giant system prompt required:

```python
endpoint = run.deploy()
```

### Key parameters

- **`context`:** the text you want the model to know without resending it every time (your entire system prompt, instructions and examples, or large chunks of docs and runbooks via `Context.from_text(...)`, `Context.from_file(...)`, or `Context.from_uri("s3://...")`).
- **`num_tokens`:** how small to compress that context. Generally `256` works fine, and you can experiment with increasing it (for example, `512` or `1024`) for very large contexts. Compare answer accuracy in `eval_report` against the full-context model to check quality.
- **`teacher`:** optional. Defaults to the same model as `model=`, or pass a larger model if you also want to distill from a stronger teacher.
- **`optim.AdamW(lr=...)`:** Cartridges need a higher learning rate (`1e-2` to `2e-2`) than LoRA adapters.

## When to use Cartridges vs. distillation vs. RAG

- **Use `CartridgeRecipe`** whenever you have a long system prompt, instructions, or large chunk of reference docs you don't want to resend on every request.
- **Use [Model distillation](/docs/training/recipes/distillation/) (`DistillRecipe`)** when you want a smaller model to imitate a bigger teacher model overall (you can also pass `context=` to bake a prompt straight into a LoRA fine-tune).
- **Use RAG ([Embeddings](/docs/training/recipes/embeddings/))** when your knowledge base changes every minute or has millions of documents. Cartridges work best for 10k to 100k tokens of context that stay mostly stable.

### Baking context into a LoRA fine-tune instead

If you prefer a regular LoRA fine-tune instead of a Cartridge, pass `context=` to [`DistillRecipe`](/docs/training/recipes/distillation/):

```python
from grad import Context, adapters, losses
from grad.recipes import DistillRecipe, OnPolicy

recipe = DistillRecipe(
    model="qwen/qwen3-8b",
    teacher="qwen/qwen3-8b",
    context=Context.from_uri("s3://my-bucket/api-docs-bundle.md"),
    adapter=adapters.LoRA(rank=32),
    rollout=OnPolicy(max_new_tokens=512),
    loss=losses.TopKKLDistill(top_k=32),
)

run = client.runs.create(dataset=dataset, name="api-docs-prompt-distilled", recipe=recipe).wait()
```
