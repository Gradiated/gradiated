# Decision models

<DocsLead>Train your own fast decision model and call it directly through the SystemOne / TypeSafe SDK.</DocsLead>

A **decision model** takes a `state` (text, JSON, or a chat transcript) and answers one or more named `questions` in a single request — returning choices, probabilities, and scores instead of free-form text.

Use **`DecisionModelRecipe`** when you already use [`gradiated/linden-1`](/docs/systemone-sdk/) (or Jev) through the TypeSafe SDK and want a faster, more accurate model trained on your own traffic. Once deployed, your trained model drops straight into `TypeSafeClient` by changing only the `model` name.

## Question types

Every decision model supports the three [SystemOne](/docs/systemone-sdk/) question types, and can answer multiple questions in a single call:

- **`Choice`** — pick one category from a fixed list (`billing`, `technical`, `other`). Returns the chosen option, probabilities for every option, and a `confidence` score.
- **`Noul`** — a yes/no probability from `0` to `1` (`"Does this need immediate attention?"`). Apply your own threshold in code.
- **`Score`** — an ordered rating across criteria (`["Can wait", "Needs attention today", "Needs immediate attention"]`), so confusing the two extremes costs more than mixing up neighboring levels.

## What data you need

- **Already calling `gradiated/linden-1`?** Requests sent with the `x-gradiated-task` header are captured in the right format automatically, so you can go straight to scoring or training.
- **Pushing your own data?** Store examples in a [`Dataset`](/docs/training/trajectories/) with `state` and `questions` in `input.payload` and the expected answers in `expected_output`. Plan for ~200 examples per option to start (1,000+ for harder decisions).
- **Don't have labels yet?** Score an unlabeled dataset first with a [`Judge`](/docs/training/rubrics/) (or `gradiated/linden-1`), review a sample, and train on those answers.

```python
from grad import Grad, Trajectory, TrajectoryInput

client = Grad()
dataset = client.datasets.create("ticket-triage")

dataset.push([
    Trajectory(
        session_id="ticket_104",
        input=TrajectoryInput(
            payload={
                "state": {"ticket": "I was charged twice. Please fix this today."},
                "questions": {
                    "category": {
                        "type": "choice",
                        "instructions": "Choose the department for this ticket.",
                        "criteria": {
                            "billing": "Charges or payments",
                            "technical": "Something is broken",
                            "other": "Anything else",
                        },
                    },
                    "urgent": {
                        "type": "noul",
                        "instructions": "Does this need immediate attention?",
                    },
                    "effort": {
                        "type": "score",
                        "instructions": "Rate how urgently this ticket needs attention.",
                        "criteria": ["Can wait", "Needs attention today", "Needs immediate attention"],
                    },
                },
            },
        ),
        expected_output={
            "category": "billing",
            "urgent": 1.0,
            "effort": 2,
        },
    ),
])
```

## Train the decision model

`DecisionModelRecipe` picks the right loss automatically for each question type (`losses.CrossEntropy()` for `choice`, `losses.BCEWithLogits()` for `noul`, and `losses.OrdinalBCE()` for `score`).

Choose your base `model`:

- **`"gradiated/linden-1"`** *(default)* — best starting point when you want to specialize `linden-1` on your own questions and state format.
- **`"qwen/qwen3-0.6b"`** — smallest general open model if you want to train a lightweight decision model from scratch.

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Grad, splits
from grad.recipes import DecisionModelRecipe

client = Grad()
dataset = client.datasets.get("ticket-triage")

recipe = DecisionModelRecipe(
    model="gradiated/linden-1",
    split=splits.BySession(eval_fraction=0.15),
)

run = client.runs.create(dataset=dataset, name="ticket-triage", recipe=recipe).wait()

print(run.artifact.id)
print(run.eval_report)
```

### When to use a decision model vs. a router vs. SFT

- **Use a decision model (`DecisionModelRecipe`)** when your app needs structured judgments — picking a category (`Choice`), returning a yes/no probability (`Noul`), or rating on a scale (`Score`) — and calling it through the [SystemOne SDK](/docs/systemone-sdk/).
- **Use a [Model router](/docs/training/recipes/router/)** when the decision is specifically *which LLM should answer this prompt* to save money within a quality budget.
- **Use [Supervised fine-tuning (SFT)](/docs/training/recipes/sft/)** when the model needs to generate free-form text, JSON, SQL, or code edits.

### Key parameters

- **`model`:** defaults to `"gradiated/linden-1"` (best for specializing `linden-1` on your own questions). Pass `"qwen/qwen3-0.6b"` if you want to train a fresh lightweight model from scratch.
- **`loss`:** picked automatically from each question type (`losses.CrossEntropy()` for `choice`, `losses.BCEWithLogits()` for `noul`, `losses.OrdinalBCE()` for `score`); pass `loss=` only if you want to override it.
- **`split`:** `splits.BySession(eval_fraction=0.15)` keeps related requests from the same `session_id` together so eval numbers stay honest.

## Read the evaluation report

Check `run.eval_report` before shipping:

- **Check each option separately, not just overall accuracy:** if 95% of your tickets are `"other"` and 5% are `"billing"`, a broken model that always picks `"other"` still scores 95% overall. Look at the per-option numbers in `run.eval_report` to make sure rare options (like escalations or safety flags) are actually caught rather than missed.
- **Look at which mistakes happen (`confusion_matrix`):** for ordered `score` questions (`0 / 1 / 2`), mixing up neighbors (`0` vs `1`) is normal. If the model frequently confuses `0` with `2`, add more examples of those edge cases.
- **Check if confidence scores are honest (`ece`):** this measures how closely the model's confidence matches reality — when it says 80% confident, it should be right around 80% of the time. Aim for under `0.05` so confidence checks in your app code behave predictably.

## Deploy and call from the TypeSafe SDK

Deploy the trained [`Artifact`](/docs/training/artifacts/) to an [`Endpoint`](/docs/training/endpoints/) in one line:

```python
endpoint = run.deploy()
```

Your endpoint is immediately callable through the [SystemOne SDK](/docs/systemone-sdk/) (`TypeSafeClient`) by passing `"<org>/ticket-triage"` as the `model`.

Confidence scores are calibrated automatically during training, so you can fall back in your own code whenever the model isn't sure enough (for example, escalating a ticket or calling `gradiated/linden-1` when confidence is below `0.75`):

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
import os
from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

with TypeSafeClient(
    base_url="https://api.gradiated.com",
    api_key=os.environ["GRADIATED_API_KEY"],
    model="<org>/ticket-triage",
) as ts_client:
    response = ts_client.system_one(
        state={"ticket": "I was charged twice. Please fix this today."},
        questions={
            "category": Choice(
                instructions="Choose the department for this ticket.",
                criteria={
                    "billing": "Charges or payments",
                    "technical": "Something is broken",
                    "other": "Anything else",
                },
            ),
            "urgent": Noul(instructions="Does this need immediate attention?"),
            "effort": Score(
                instructions="Rate how urgently this ticket needs attention.",
                criteria=["Can wait", "Needs attention today", "Needs immediate attention"],
            ),
        },
    )

cat = response.choices["category"]
# Fall back in your own code when the model isn't confident enough
department = cat.choice if cat.confidence >= 0.75 else "human_review"
is_urgent = response.nouls["urgent"].noul >= 0.5
urgency = response.scores["effort"].score
```

```javascript
import { choice, noul, score, TypeSafeClient } from "@typesafe-ai/sdk";

const tsClient = new TypeSafeClient({
  baseURL: "https://api.gradiated.com",
  apiKey: process.env.GRADIATED_API_KEY,
  defaultModel: "<org>/ticket-triage",
});

const response = await tsClient.systemOne({
  state: { ticket: "I was charged twice. Please fix this today." },
  questions: {
    category: choice("Choose the department for this ticket.", {
      billing: "Charges or payments",
      technical: "Something is broken",
      other: "Anything else",
    }),
    urgent: noul("Does this need immediate attention?"),
    effort: score("Rate how urgently this ticket needs attention.", [
      "Can wait",
      "Needs attention today",
      "Needs immediate attention",
    ]),
  },
});

const cat = response.answers.category;
// Fall back in your own code when the model isn't confident enough
const department = cat.confidence >= 0.75 ? cat.choice : "human_review";
const isUrgent = response.answers.urgent.noul >= 0.5;
const urgency = response.answers.effort.score;
```
