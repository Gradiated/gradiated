# Model distillation

<DocsLead>Train a small, fast model to copy a larger one using your own prompts.</DocsLead>

If you just fine-tune a small model on saved outputs from a big model, it can go off the rails as soon as it starts writing its own slightly different wording. **`DistillRecipe`** fixes that by training on-policy: the small **student** generates answers to your prompts, and the larger **teacher** scores those exact tokens so the student learns to recover from its own mistakes.

## What data you need

- **Only prompts:** you don't need labeled answers; 1,000–5,000 real prompts are enough. Plain chat records (`{"messages": [...]}` ending in a user turn), Hugging Face datasets via `client.datasets.from_hf(...)`, or imported [trajectories](/docs/training/trajectories/) all work. Any assistant turns at the end are ignored, because the student writes its own.
- **A teacher model:** any larger base model (such as `"qwen/qwen3-32b"`) or a fine-tuned `.grad` [`Artifact`](/docs/training/artifacts/) you trained earlier.

## Train with `DistillRecipe`

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Grad
from grad.recipes import DistillRecipe

client = Grad()
dataset = client.datasets.get("support-prompts")  # pushed or imported earlier

run = client.runs.create(
    dataset=dataset,
    name="support-4b-distilled",
    recipe=DistillRecipe(model="qwen/qwen3-4b", teacher="qwen/qwen3-32b"),
).wait()

print(run.artifact.id, run.eval_report)
```

import { Grad, recipes } from "@gradiated/grad";

const grad = new Grad();
const dataset = await grad.datasets.get("support-prompts");

const run = await grad.runs
  .create({

    name: "support-4b-distilled",

  .wait();

### Parameters you might change

- **`teacher`:** the stronger model you want to copy, either a catalog model (like `"qwen/qwen3-32b"`) or a larger `.grad` [`Artifact`](/docs/training/artifacts/) you already fine-tuned.
- **`rollout`:** on-policy by default: the student writes answers and the teacher grades those exact tokens. Pass `rollout=OffPolicy()` only if you already have fixed teacher completions you want to train on directly.
- **`loss`:** by default the student matches the teacher's top 32 next-token probabilities at every step, which captures almost all the signal.

**Teacher and student must share a tokenizer** for token-level distillation (the Qwen3 family does). For a teacher with a different tokenizer (including frontier API models), generate its answers and train on them with [`SFTRecipe`](/docs/training/recipes/sft/) instead.

Every other setting has a default; see the [training parameters reference](/docs/reference/training-parameters/#distillrecipe). Add `--dry-run` to `grad train` to see the cost estimate, including teacher scoring, before you start.

## When to use distillation vs. SFT vs. Cartridges

- **`DistillRecipe`:** you have a strong, slow model (like a 32B or frontier model) and want a small 4B–8B model to match it on your prompts, with no labeled answers required.
- **[`SFTRecipe`](/docs/training/recipes/sft/):** you already have verified gold answers (or human-edited outputs) you want the model to copy directly.
- **[`CartridgeRecipe`](/docs/training/recipes/cartridges/):** you don't want to change the model's general behavior; you just want to stop resending the same long docs or system prompt (up to ~500k tokens) on every request.

## Deploy and serve

Distilled checkpoints export as standard `.grad` [`Artifact`](/docs/training/artifacts/)s. Host on Gradiated Cloud with `run.deploy(canary=0.10)` and call `"your-org/support-4b-distilled"` via the OpenAI or Anthropic SDK, or download the LoRA weights for vLLM / SGLang (see [Deploying](/docs/training/deploying/)):

```python
run.deploy(canary=0.10)
```

## Want more control?

Need custom distillation losses (like Jensen-Shannon / GKD or Skew KL) or Self-Distillation Fine-Tuning (SDFT) to teach new skills without the model forgetting what it already knows? See [Advanced objectives](/docs/training/advanced-objectives/) and [Custom loops](/docs/training/custom-loops/).
