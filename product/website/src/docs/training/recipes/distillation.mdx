# Model distillation

<DocsLead>Shrink a slow frontier or 32B teacher model into a fast 4B–8B student using on-policy distillation on your production prompts — no gold answers required.</DocsLead>

Offline SFT on teacher outputs teaches the student what the teacher says on *teacher* prefixes, which drifts as soon as the student generates its own tokens. **`DistillRecipe`** with on-policy rollouts (`rollout=OnPolicy(...)`) samples from the **student**, scores those exact sequences with the **teacher's** probabilities, and minimizes KL divergence where the student actually goes.

## What data you need

- **Only prompts:** You do not need gold answers — 1,000–5,000 representative production prompts in `input.messages` ([trajectories](/docs/training/trajectories/)) are enough.
- **A teacher model:** Any catalog `Model` (`Model("Qwen/Qwen3-32B")`) or a larger fine-tuned `.grad` [`Artifact`](/docs/training/artifacts/) you trained earlier.

## Train with `DistillRecipe`

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Grad, Model, adapters, losses, optim
from grad.recipes import DistillRecipe, OnPolicy

client = Grad()
dataset = client.datasets.get("support-prompts")

recipe = DistillRecipe(
    model=Model("Qwen/Qwen3-4B"),
    teacher=Model("Qwen/Qwen3-32B"),
    adapter=adapters.LoRA(rank=32, merge_on_export=True),
    rollout=OnPolicy(max_new_tokens=512),
    loss=losses.TopKKLDistill(top_k=32),
    optimizer=optim.AdamW(lr=1e-4),
)

run = client.runs.create(dataset=dataset, name="support-4b-distilled", recipe=recipe).wait()

print(run.artifact.id, run.eval_report)
```

  </DocsCodeTab>
  <DocsCodeTab label="TypeScript">

```ts
import { Grad, Model, adapters, losses, optim, recipes } from "@gradiated/grad";

const grad = new Grad();
const dataset = await grad.datasets.get("support-prompts");

const run = await grad.runs
  .create({
    dataset,
    name: "support-4b-distilled",
    recipe: recipes.distill({
      model: new Model("Qwen/Qwen3-4B"),
      teacher: new Model("Qwen/Qwen3-32B"),
      adapter: adapters.lora({ rank: 32, mergeOnExport: true }),
      rollout: recipes.onPolicy({ maxNewTokens: 512 }),
      loss: losses.topKKLDistill({ topK: 32 }),
      optimizer: optim.adamW({ lr: 1e-4 }),
    }),
  })
  .wait();

console.log(run.artifact.id, run.evalReport);
```

  <DocsCodeTab label="CLI (YAML)">

```yaml
# distill-4b.yaml
dataset: support-prompts
name: support-4b-distilled
recipe: distill
model: Qwen/Qwen3-4B
teacher: Qwen/Qwen3-32B
adapter:
  kind: lora
  rank: 32
  merge_on_export: true
rollout:
  kind: on_policy
  max_new_tokens: 512
loss:
  kind: topk_kl_distill
  top_k: 32
optimizer:
  kind: adamw
  lr: 1e-4
```

```bash
grad train -f distill-4b.yaml --wait
```

## Deploy and serve

Distilled checkpoints export as standard `.grad` [`Artifact`](/docs/training/artifacts/)s and deploy onto any [`Endpoint`](/docs/training/endpoints/) with `strategies.Direct()` (or `strategies.Cascade` paired with a [reward model](/docs/training/recipes/reward-models/)):

```python
endpoint = run.deploy(canary=0.10)
```
