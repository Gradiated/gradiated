# Model distillation

<DocsLead>Train a small, fast model to copy a larger one using your own prompts.</DocsLead>

If you just fine-tune a small model on saved outputs from a big model, it can go off the rails as soon as it starts writing its own slightly different wording. **`DistillRecipe`** with `rollout=OnPolicy(...)` fixes that: the small **student** generates answers to your prompts, and the larger **teacher** scores those exact tokens so the student learns to recover from its own mistakes.

## What data you need

- **Only prompts:** you don't need labeled answers; 1,000–5,000 real prompts are enough. Plain chat records (`{"messages": [...]}` ending in a user turn), Hugging Face datasets via `client.datasets.from_hf(...)`, or imported [trajectories](/docs/training/trajectories/) all work. Any assistant turns at the end are ignored, because the student writes its own.
- **A teacher model:** any larger base model (such as `"qwen/qwen3-32b"`) or a fine-tuned `.grad` [`Artifact`](/docs/training/artifacts/) you trained earlier.

## Train with `DistillRecipe`

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Grad, losses
from grad.recipes import DistillRecipe, OnPolicy

client = Grad()
dataset = client.datasets.get("support-prompts")  # pushed or imported earlier

recipe = DistillRecipe(
    model="qwen/qwen3-4b",
    teacher="qwen/qwen3-32b",
    rollout=OnPolicy(max_new_tokens="auto"),  # p95 of the student's answer length
    loss=losses.TopKKLDistill(top_k=32),
    # Defaults: LoRA(rank=32), lr="auto" (about 2e-4 here), batch_size=128
)
print(client.runs.plan(dataset=dataset, recipe=recipe))  # $0 estimate, incl. teacher scoring

run = client.runs.create(
    dataset=dataset,
    name="support-4b-distilled",
    recipe=recipe,
    max_cost_usd=40,
).wait()

print(run.artifact.id, run.eval_report)
```

```ts
import { Grad, losses, recipes } from "@gradiated/grad";

const grad = new Grad();
const dataset = await grad.datasets.get("support-prompts");

const run = await grad.runs
  .create({
    dataset,
    name: "support-4b-distilled",
    recipe: recipes.distill({
      model: "qwen/qwen3-4b",
      teacher: "qwen/qwen3-32b",
      rollout: recipes.onPolicy({ maxNewTokens: "auto" }),
      loss: losses.topKKLDistill({ topK: 32 }),
    }),
    maxCostUsd: 40,
  })
  .wait();

console.log(run.artifact.id, run.evalReport);
```

### Key parameters

- **`teacher`:** the stronger model you want to copy, either a catalog model (like `"qwen/qwen3-32b"`) or a larger `.grad` [`Artifact`](/docs/training/artifacts/) you already fine-tuned.
- **`rollout=OnPolicy(max_new_tokens="auto")`:** generates answers from the student and grades them with the teacher so the student learns where it actually makes mistakes. `"auto"` sets the length limit to the 95th percentile of the student's answer length on 64 sampled prompts, measured during `runs.plan()`; the plan and live metrics report `truncation_rate`. Switch to `OffPolicy()` only if you already have fixed teacher completions you want to train on directly.
- **`losses.TopKKLDistill(top_k=32)`:** matches the teacher's top 32 next-token probabilities at every step (`top_k=16..32` captures almost all the signal cleanly).
- **`lr="auto"`** *(default)*: for a LoRA student it typically resolves to about `2e-4` at batch 128 (lower than SFT, higher than RL). The dry run prints the exact value.
- **`adapter=adapters.LoRA(rank=32)`** *(default)*, with `alpha=32` fixed. Checkpoints are saved every 10% of steps; `run.artifact` is the checkpoint with the lowest held-out KL to the teacher.
- **Teacher and student must share a tokenizer** for token-level KL (the Qwen3 family does). For a teacher with a different tokenizer (including frontier API models), generate its answers and train on them with [`SFTRecipe`](/docs/training/recipes/sft/) instead.

## When to use distillation vs. SFT vs. Cartridges

- **`DistillRecipe`:** you have a strong, slow model (like a 32B or frontier model) and want a small 4B–8B model to match it on your prompts, with no labeled answers required.
- **[`SFTRecipe`](/docs/training/recipes/sft/):** you already have verified gold answers (or human-edited outputs) you want the model to copy directly.
- **[`CartridgeRecipe`](/docs/training/recipes/cartridges/):** you don't want to change the model's general behavior; you just want to stop resending the same long docs or system prompt (up to ~500k tokens) on every request.

## Deploy and serve

Distilled checkpoints export as standard `.grad` [`Artifact`](/docs/training/artifacts/)s. Host on Gradiated Cloud with `run.deploy(canary=0.10)` and call `"your-org/support-4b-distilled"` via the OpenAI or Anthropic SDK, or download the LoRA weights for vLLM / SGLang (see [Deploying](/docs/training/deploying/)):

```python
run.deploy(canary=0.10)
```
