# Embeddings

<DocsLead>Fine-tune an embedding model on your own terms, docs, and codebase for better search.</DocsLead>

General-purpose embedding models often miss internal acronyms, product names, and custom schemas. Fine-tuning a small encoder with **`EmbeddingRecipe`** on your own query/document pairs usually boosts top-10 search hit rate by 10–25 points while staying under 10 ms per request.

## What data you need

- **Minimum volume:** 1,000–5,000 query groups in a [`Dataset`](/docs/training/trajectories/) sharing a `group_id` with `role: "anchor"` (the query), `role: "positive"` (the right document), and one or more `role: "negative"` (wrong documents that look similar).
- **Use near-miss negatives:** random wrong documents are too easy to tell apart; pull close-but-wrong results from your current search or RAG pipeline.

## Train with `EmbeddingRecipe`

<DocsCodeTabs action={<DocsApiKeyAction />}>
  <DocsCodeTab label="Python">

```python
from grad import Grad, Model, adapters, losses, optim, pooling
from grad.recipes import EmbeddingRecipe

client = Grad()
dataset = client.datasets.get("docs-retrieval-triplets")

recipe = EmbeddingRecipe(
    model=Model("BAAI/bge-small-en-v1.5"),
    adapter=adapters.Full(),
    pool=pooling.Mean(),
    loss=losses.InfoNCE(temp=0.05),
    optimizer=optim.AdamW(lr=2e-5),
)

run = client.runs.create(dataset=dataset, name="docs-embedder", recipe=recipe).wait()

print(run.artifact.id, run.eval_report)
```

  </DocsCodeTab>
  <DocsCodeTab label="TypeScript">

```ts
import { Grad, Model, adapters, losses, optim, pooling, recipes } from "@gradiated/grad";

const grad = new Grad();
const dataset = await grad.datasets.get("docs-retrieval-triplets");

const run = await grad.runs
  .create({
    dataset,
    name: "docs-embedder",
    recipe: recipes.embedding({
      model: new Model("BAAI/bge-small-en-v1.5"),
      adapter: adapters.full(),
      pool: pooling.mean(),
      loss: losses.infoNCE({ temp: 0.05 }),
      optimizer: optim.adamW({ lr: 2e-5 }),
    }),
  })
  .wait();

console.log(run.artifact.id, run.evalReport);
```

## Embed offline or deploy to an endpoint

Extract normalized embeddings directly from the exported [`Artifact`](/docs/training/artifacts/) or deploy it behind a `strategies.Direct()` [`Endpoint`](/docs/training/endpoints/) to serve live retrieval traffic:

```python
from grad import Record, pooling

vectors = run.artifact.embed(
    [Record(text="rotate api keys")],
    pool=pooling.Mean(),
).embeddings

endpoint = run.deploy()
```
