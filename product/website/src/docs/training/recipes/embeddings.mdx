# Embeddings and rerankers

<DocsLead>Fine-tune domain-specific dense embeddings, ColBERT multi-vector retrievers, and cross-encoder rerankers with built-in InfoNCE and batched hard-negative mining.</DocsLead>

Off-the-shelf embedding models degrade on internal jargon, codebases, and domain-specific schemas. Fine-tuning a compact encoder on your own query/document pairs typically recovers 10–25 points of Recall@10 while keeping latency under 10 ms.

## What data you need

Group each query with its positive document and one or more hard negatives using `group_id` and `role` (`anchor`, `positive`, `negative`):

- **Minimum volume:** 1,000–5,000 query groups for domain adaptation.
- **Hard negatives matter most:** Random negatives saturate quickly; mine near-miss documents from your existing retriever or refresh them periodically with `trainer.snapshot()`.

## 1. Dense bi-encoder (`losses.InfoNCE`)

Train a mean-pooled encoder with `losses.InfoNCE`, then extract normalized embeddings directly from the exported [Artifact](/docs/training/endpoints/):

```python
from grad import Datum, Grad, ModelInput, adapters, losses, optim

client = Grad()
base = client.models.get("BAAI/bge-small-en-v1.5")

datums = [
    Datum(ModelInput(tokens=base.tokenize("how to rotate api keys")), group_id="q0", role="anchor"),
    Datum(ModelInput(tokens=base.tokenize("API key rotation procedure and revocation")), group_id="q0", role="positive"),
    Datum(ModelInput(tokens=base.tokenize("Configuring OAuth redirect URIs")), group_id="q0", role="negative"),
]

with client.trainers.create(
    model=base,
    adapter=adapters.Full(),
    pool="mean",
) as trainer:
    for batch in query_batches:
        m = trainer.forward_backward(batch, loss=losses.InfoNCE(temp=0.05)).result()
        trainer.optim_step(optim.AdamW(lr=2e-5)).result()

    embed_artifact = trainer.export(name="docs-embedder")

vectors = embed_artifact.embed(
    [ModelInput(tokens=embed_artifact.tokenize("rotate api keys"))],
    pool="mean",
).embeddings
```

## 2. Multi-vector (ColBERT) and Matryoshka embeddings

Set `pool="none"` to receive full per-token embeddings `(L, D)` inside a `losses.CustomLoss`, using `grad.by_group()` so arbitrary batch sizes stay shuffle-safe across ColBERT MaxSim and Matryoshka nested prefixes:

```python
import torch
import torch.nn.functional as F
import grad
from grad import losses

class MatryoshkaColBERTLoss(losses.CustomLoss):
    outputs = ("embeddings",)

    def __init__(self, dims: tuple[int, ...] = (128, 256, 384)):
        self.dims = dims

    def compute(self, datums, out) -> torch.Tensor:
        terms = []
        for g in grad.by_group(datums, out):
            q_tok, p_tok, n_tok = g["anchor"].embeddings, g["positive"].embeddings, g["negative"].embeddings
            qm, pm, nm = q_tok.mean(0), p_tok.mean(0), n_tok.mean(0)
            mrl = sum(
                F.cross_entropy(
                    torch.stack([
                        F.normalize(qm[:d], dim=-1) @ F.normalize(pm[:d], dim=-1),
                        F.normalize(qm[:d], dim=-1) @ F.normalize(nm[:d], dim=-1),
                    ]).unsqueeze(0) / 0.05,
                    torch.tensor([0]),
                )
                for d in self.dims
            ) / len(self.dims)
            qc, pc, nc = F.normalize(q_tok, dim=-1), F.normalize(p_tok, dim=-1), F.normalize(n_tok, dim=-1)
            colbert = F.cross_entropy(
                torch.stack([(qc @ pc.T).max(-1).values.sum(), (qc @ nc.T).max(-1).values.sum()]).unsqueeze(0) / 0.1,
                torch.tensor([0]),
            )
            terms.append(mrl + colbert)
        return torch.stack(terms).mean()
```

At serving time, override pooling per call on the exported artifact (`embed_artifact.embed(inputs, pool="none").embeddings` for token vectors or `pool="mean"` for a single dense vector).

## 3. Cross-encoder reranker with hard-negative refresh

Pair `(query, document)` sequences into a cross-encoder with a relevance head (`heads.Linear(dim=1)`). Periodically score your corpus with `trainer.snapshot().infer_batch(...)` to pull the highest-scoring false positives into the next training epoch:

```python
import torch
import torch.nn.functional as F
import grad
from grad import Grad, Model, adapters, heads, losses, optim

class ListNetRerankLoss(losses.CustomLoss):
    outputs = ("heads",)

    def compute(self, datums, out) -> torch.Tensor:
        terms = []
        for g in grad.by_group(datums, out):
            pos = g["positive"].heads["rel"][0]
            negs = [v.heads["rel"][0] for role, v in g.items() if role.startswith("negative")]
            terms.append(F.cross_entropy(torch.stack([pos, *negs]).unsqueeze(0), torch.tensor([0])))
        return torch.stack(terms).mean()

client = Grad()

with client.trainers.create(
    model=Model("BAAI/bge-reranker-base"),
    adapter=adapters.Full(),
    heads={"rel": heads.Linear(dim=1)},
) as trainer:
    for epoch in range(3):
        snap = trainer.snapshot()
        # Mine fresh hard negatives with batched inference
        cand_scores = [res.logits.item() for res in snap.infer_batch(candidate_pairs)]
        hard_batch = build_listnet_batch(queries, positives, candidate_pairs, cand_scores)

        trainer.forward_backward(hard_batch, loss=ListNetRerankLoss()).result()
        trainer.optim_step(optim.AdamW(lr=2e-5)).result()

    reranker = trainer.export(name="docs-reranker")
```
