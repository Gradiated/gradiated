# Self-hosting

<DocsLead>Run the Gradiated training API and GPU trainer workers on your laptop with Docker Compose or in your own Kubernetes cluster with Helm.</DocsLead>

Self-hosted deployments run the **training, evaluation, and dataset platform** inside your own VPC so prompts, traces, and trained weights never leave your network. Completed runs write standard HuggingFace LoRA or merged Safetensors [`Artifact`](/docs/training/artifacts/)s to your own S3 or GCS bucket, ready to serve on your own vLLM or SGLang cluster.

Switching between local, self-hosted Kubernetes, and Gradiated Cloud only requires changing `GRAD_BASE_URL`.

## Local development (Docker Compose)

Start a local training stack in one command with the `grad` CLI:

```bash
brew install gradiated/tap/grad

# CPU stack (default): datasets, trace sync, rubrics, and small local runs
grad local up

# GPU stack (requires NVIDIA Container Toolkit): adds CUDA trainer worker
grad local up --gpu
```

`grad local up` starts the API on `http://localhost:8787`, Postgres, local object storage, and a trainer worker. Run `grad local down` to stop and clean up.

## Production Kubernetes (Helm)

Deploy `grad` into an internal ML namespace in your Kubernetes cluster using the official Helm chart. It runs the CPU API server and scale-to-zero GPU trainer workers on your existing Postgres and S3/GCS bucket, with no hot-path production gateway in front of user traffic:

```bash
helm repo add gradiated https://charts.gradiated.com
helm repo update

helm upgrade --install grad gradiated/grad \
  --namespace grad \
  --create-namespace \
  -f values.yaml
```

### Minimal `values.yaml`

```yaml
# values.yaml
api:
  replicas: 2
  ingress:
    enabled: true
    className: nginx
    hosts:
      - host: grad.internal.example
        paths:
          - path: /
            pathType: Prefix
    tls:
      - secretName: grad-tls
        hosts:
          - grad.internal.example

# Reference a Kubernetes Secret holding ADMIN_API_KEY_HASH, DATABASE_URL, and S3 credentials
auth:
  existingSecret: grad-secrets

storage:
  s3:
    bucket: my-org-grad-artifacts
    region: us-east-1

trainer:
  gpu:
    enabled: true
    # Scale to zero between training runs with Karpenter or KEDA
    minReplicas: 0
    maxReplicas: 4
    resources:
      limits: { nvidia.com/gpu: "1" }
    nodeSelector:
      accelerator: nvidia-h100
    tolerations:
      - key: nvidia.com/gpu
        operator: Exists
        effect: NoSchedule
```

### Private VPC & air-gapped setup

To keep container pulls, base model downloads, and `Judge` calls completely inside your VPC, add three blocks to `values.yaml`:

```yaml
# Mirror ghcr.io/gradiated/grad-server and grad-trainer to your internal registry
image:
  registry: 123456789012.dkr.ecr.us-east-1.amazonaws.com/gradiated
  pullSecrets:
    - name: ecr-creds

# Load base models and open distillation teachers from your internal bucket instead of Hugging Face
models:
  mirrorUri: s3://my-org-approved-models/
  offline: true

# Route Judge calls (and off-policy text distillation) to your internal OpenAI-compatible gateway
judge:
  baseUrl: https://llm-gateway.internal.example/v1
  existingSecret: internal-llm-creds
```

On-policy logprob distillation (`TopKKLDistill`) loads open teacher weights (such as `qwen/qwen3-32b`) directly from `models.mirrorUri` onto your own trainer GPUs, so it never needs an external API call.

### Authentication & API keys

Self-hosted authentication is 100% local to your cluster (it never phones home to Gradiated Cloud) while keeping the same `GRADIATED_API_KEY` environment variable and `Authorization: Bearer` header as Cloud:

- **Local dev (`grad local up`):** authentication is off by default on `localhost:8787`.
- **Scoped API keys (default in Kubernetes):** set `ADMIN_API_KEY_HASH` in `grad-secrets` (synced from AWS Secrets Manager, Vault, or External Secrets) to bootstrap your cluster. Use that key directly or mint scoped per-pipeline keys stored as SHA-256 hashes in your own Postgres:

```bash
export GRAD_BASE_URL=https://grad.internal.example
export GRADIATED_API_KEY=<bootstrap-admin-key>

# Mint a least-privilege key for nightly training jobs
grad keys create --name ci-nightly --scopes datasets:write,runs:write,artifacts:read

# Or an artifacts-only key for your vLLM / SGLang deployment pipeline
grad keys create --name inference-cd --scopes artifacts:read

grad keys list
grad keys revoke key_01j...
```

- **OIDC / short-lived JWTs (optional):** if your org bans static keys, add `auth.oidc` in `values.yaml` so `grad-server` accepts JWTs from GitHub Actions OIDC, Kubernetes ServiceAccounts, or Okta/Entra in the same `Authorization: Bearer` header:

```yaml
auth:
  existingSecret: grad-secrets
  oidc:
    issuer: https://token.actions.githubusercontent.com
    audience: https://grad.internal.example
```

## Connect SDKs and CLI

Point the SDK or CLI at your local or self-hosted URL via `GRAD_BASE_URL` (or pass `base_url` / `baseURL` directly):

<DocsCodeTabs>
  <DocsCodeTab label="Python">

```python
import os
from grad import Grad

# Or set GRAD_BASE_URL=https://grad.internal.example in your environment
client = Grad(
    base_url="https://grad.internal.example",
    api_key=os.environ["GRADIATED_API_KEY"],
)
```

  </DocsCodeTab>
  <DocsCodeTab label="TypeScript">

```ts
import { Grad } from "@gradiated/grad";

const grad = new Grad({
  baseURL: "https://grad.internal.example",
  apiKey: process.env.GRADIATED_API_KEY,
});
```

package main

import (
	"os"

## Self-hosted vs. Gradiated Cloud

Self-hosting gives you the complete training and evaluation platform inside your VPC while letting you keep your existing production inference stack (vLLM, SGLang, Envoy, Argo Rollouts). Gradiated Cloud adds elastic per-token training GPUs and managed production serving on top:

| Capability | Self-hosted (Docker / Helm) | Gradiated Cloud |
| --- | --- | --- |
| Datasets, trace sync, & `feedback.record()` | Included (your Postgres + S3) | Included (managed) |
| All recipes, rubrics, environments, & custom loops | Included (runs on your GPUs, scales to 0) | Included (pay per million tokens) |
| Artifacts (PEFT LoRA / merged Safetensors) | Written to your S3/GCS; serve on your vLLM or SGLang | Downloadable anytime, or host with `run.deploy()` |
| Hosted production serving | Bring your own vLLM/SGLang + gateway/feature flags | Built-in (`run.deploy()` + OpenAI/Anthropic/SystemOne SDK) |
| Zero-code gateway trace capture | Push via SDK or sync from OTel / Langfuse | Automatic via `x-gradiated-task` |
