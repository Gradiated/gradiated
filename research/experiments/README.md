# Experiment records

Conversation traces and supporting evidence for future posts, not finished
posts. Start a record with `$experiment-record`.

Use `YYYY-MM-DD-short-name/` with the experiment's start date. Each folder has
a thin bullet-point `README.md`, conversation exports in `traces/`, and useful
aggregate `data/` and `figures/`. Keep restricted data and secrets at their
authorized location. Label export coverage, redactions, and missing tool bodies.
Do not maintain an experiment log or status index in this top-level README.
