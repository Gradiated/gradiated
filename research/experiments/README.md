# Experiment records

Working evidence for future posts, not finished posts. Start a record with
`$experiment-record` and keep it current as the experiment develops.

Use `YYYY-MM-DD-short-name/` with the experiment's start date. Each folder has
a simple `README.md` and, when useful, small `data/` summaries and `figures/`.
Record failed attempts and caveats alongside successes. Keep restricted raw
data and routine logs at their authorized runtime location.

- [2026-11-02 — PostHog AI agent](2026-11-02-posthog-ai-agent/): synthetic task
  quality, difficulty calibration, correction collection, serving throughput,
  SFT, and privileged-context OPD. Follow-up evaluations remain in progress.
