## 2026-07-23 — ownership repair reopened by user direction

- The positive, bit-identical component remains settled. The endpoint failure begins only after prefill, so it localizes to runtime state integration rather than the contiguous representation.
- The leading source-level defect is `clamp(req_pool_indices - 1, min=0)`. Pinned `ReqToTokenPool` source reserves index zero for CUDA-graph padding, allocates real slots from the larger `1..size` pool, and appends freed slots; pinned graph source initializes padded request indices to zero. The candidate therefore aliases padded work onto live row zero and can map later valid slots beyond the 32-row allocation. This is source-proven unsafe, although the first stock-versus-ring local-layer comparison must still establish whether it fully explains the observed first-decode divergence.
