Question: can an Ada-native FP8 representation of the public AWQ checkpoint's BF16 residual cross the 10% c16 cost gate or unlock c32?

Action: parsed every tensor header in `/root/.cache/glm47flash-awq-ab31d120/model.safetensors.index.json` with the exact config and built [`selective_fp8_residual_bound.py`](selective_fp8_residual_bound.py). Evidence (measured headers): the 20,166,726,064-byte AWQ checkpoint leaves `lm_head` at 605.0 MiB, dense layer 0 at 161.51 MiB, and 46 shared experts at 846.0 MiB as BF16. The selected residual is 1,612.51 MiB; FP8 E4M3 payload plus conservative per-output-channel FP32 scales is 807.92 MiB, saving 804.59 MiB. Exact c16 fixture shapes include `[16,2048] x [2048,154880]`, `[16,2048] x [2048,10240]`, and shared-expert `[16,2048] x [2048,1536]`/`[16,1536] x [1536,2048]` layouts. Evidence (measured runtime capability): pinned PyTorch 2.9.1 exposes `torch.float8_e4m3fn`; vLLM's compiled `cutlass_scaled_mm_supports_fp8(89)` returns true, and `Fp8Config` reports minimum capability 75. The generic compressed-tensors W8A16-FP8 Marlin scheme is present. However, the exact AWQ config is `pack-quantized` W4 with residual modules in `ignore`; pinned `CompressedTensorsConfig.get_quant_method` assigns ignored linear layers `UnquantizedLinearMethod`, while W8A16-FP8 requires a different target scheme and FP8 checkpoint tensors/scales. No exact mixed W4-plus-selective-FP8 config/checkpoint path is present. The config's sparsity map is empty, so the allowed 2:4 fail-fast alternative is also absent.

Interpretation: the hardware primitive is real, but the exact loader route would require a new mixed checkpoint/config derivation outside this zero-cost screen. Even under the deliberately impossible model that the full retained head-plus-shared 21.19% trace ceiling is critical-path and FP8 halves all of it, the bound is only 10.595% and $0.510/M versus the $0.570827/M planning control. FP8 halves representation bytes, not GEMM work, and no trace establishes byte limitation; this is not a conservative promotion path. The observed 38,985 MiB c16 L40S footprint leaves 7,083 MiB, while doubling the KV-resident band for c32 needs multiple GiB; the 804.59 MiB save is insufficient for a credible c32 discontinuity.

Decision/next move: close selective FP8 residual architecture at zero spend. Do not build a custom mixed loader, run a provider, or pursue 2:4. Reopen only with a hash-bound mixed checkpoint and a measured L40S FP8 scaled-GEMM path that identifies residual critical-path wall time; current evidence does not justify that follow-up.
