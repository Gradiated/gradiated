Interpretation

The specialized design keeps the recurrent state in banked local memory and fuses decay, rank-1 update, and readout. This reduces state passes and synchronization.

The generic SIMT proxy exposes the cost of separate kernels. It is a useful control for GPU-like scheduling, but its resource and cycle values are not a CUDA implementation.

The full Tensor Core proxy assumes 256 parallel multiply resources. It is an intentionally non-matched upper bound. The resource-matched row scales that schedule to the measured 56-DSP budget. A real 2D KDA tile may still win, but only after we prove its banking, dependencies, timing, and arithmetic correctness in RTL.
