# Mechanism-depth research routing

Issue: https://github.com/joshsny/gradiated/issues/16

Scope: research director/researcher skills and the simple lab harness routing only.

Delivered: a director can mark a project `researcher_profile: deep`; the harness routes it to Sol high while ordinary implementation projects remain on the existing Terra/Luna pool. The skills drive source-to-hardware-to-measurement reasoning without adding a readiness gate. The live Gemma director created its first deep-profile project after deployment.

Checks: both skill validations, 17 focused harness tests, all 93 factory tests, DevEx check, JSON config validation, and live service prompt/profile inspection.
